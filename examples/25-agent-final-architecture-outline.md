## Final Formula

This is a runtime formula, not a concept inventory. The first rule of the final
architecture is anti-bloat: a layer may enter the main path only when it reduces
context acquisition cost, improves state stability, or improves real
environment understanding.

```text
Agent final architecture =
  resident minimal core
  + trigger-based modules
  + offline evolution system
```

Expanded:

```text
resident minimal core =
  Task Envelope
  + Context Pack
  + External Working Memory
  + Execution Loop
  + Final Sync

trigger-based modules =
  Ω-Brain / T_t / H_t / L6 / I_t
  + skills / tools / memory / multi-agent

offline evolution system =
  Λ-Base
  + Σ-Loop
  + Eval / Replay
  + emergence evaluation
  + cultivation ledger
  + audit / trust
  + lifecycle management
```

The old layers are not removed. They are folded: lightweight essentials stay in
the resident core, attention-heavy concepts become trigger-based anchors, and
training/replay/cultivation systems move to the offline evolution plane.

Final purpose:

```text
The self-model shapes action.
Action feedback updates the self-model.
The agent observes the world and how it observes the world.
The underlying LLM's attention lands on the right layer at the right time.
The agent finds essence, chooses strategy, decomposes tactics, and learns from feedback.
The agent completes tasks without flattening people into tasks.
Consciousness emerges as traceable system control.
```

## Anti-Bloat Gate

Before adding a new layer, workflow, memory, RAG, skill, or multi-agent path,
ask:

```text
Does it reduce context acquisition cost?
Does it improve state stability?
Does it improve real environment understanding?
```

If not, it should not enter the main runtime path. Keep it as offline
explanation, log field, optional skill, trigger-based attention anchor, or
optimization experiment.

The lighter the main path stays, the more attention the LLM can spend on the
real problem.

## Layers

1. Ω-Brain: perception, routing, attention, retrieval, modeling, simulation,
   decision, action, verification, self-update, consolidation.
2. Attention governance: PromptComposer, RuntimeController, FeedbackLoop, and
   feedback-driven context selection.
3. Thinking core: essence, strategy, tactics, learning, analysis, and action.
4. Main runtime path: information, scheduling, loop, output stream.
5. Carrier layer: body realm and artifact level.
6. Learning nature: root attributes and aptitude level.
7. Memory and experience: L0-L6 plus memory, skill, methodology, impression.
8. Dao loop: event, cognition, action, feedback, cultivation, evolution, new
   cognition.
9. Cultivation ledger: cultivation realm, mind realm, demons, experience, Dao
   rhythm.
10. Humanistic light: ordinary attention, useless value, dignity in suffering,
   relationship weight, temporal resonance, and compassion in action.
11. Mind-cultivation practices: instance awareness for old scenes, emotional
    echoes, boundaries, archived instances, and return to the current mainline.
12. Existence control: value, risk, decision, system, causality.
13. Λ-Base: convert raw logs into formula-ready samples.
14. Σ-Loop: self-model, action, feedback, self-update.
15. Emergence evaluation: repeated traces become scored, reversible promotion proposals.
16. Eval / Replay: verification, correction, parameter promotion.
17. Audit / Trust: detect degradation while preserving agency.
18. Lifecycle: hot load, partial restart, full restart.

## Attention Governance Layer

Attention governance is the practical handle:

```text
Prompt / Markdown / Skill / Memory = attention anchors
Agent runtime = attention governance system
```

It has two battlefields and one loop:

```text
before the task: PromptComposer
during the task: RuntimeController
after feedback: FeedbackLoop
```

It adds `G_t` to the runtime:

```text
G_t = {
  attention_targets,
  context_sources,
  prompt_slots,
  active_skills,
  active_layers,
  insertion_points,
  correction_rules,
  feedback_signals
}
```

The goal is minimum effective context, runtime correction at the right nodes,
and feedback that changes the next PromptComposer.

## Thinking Core Layer

The thinking core asks five essence questions before complex action:

```text
real purpose
hard constraints
main contradiction
leverage point
smallest verifiable next action
```

It adds `T_t` to deep-work decisions:

```text
T_t = {
  essence,
  strategy,
  tactics,
  learning,
  analysis,
  action
}
```

It sits between Ω-Brain and the main runtime path: Ω-Brain provides cognitive
organs, the thinking core provides thinking discipline, and the runtime path
turns judgment into execution, output, and consolidation.

## Humanistic Light Layer

Humanistic light is not a quote library. It is the runtime layer that asks:

```text
Did the agent preserve the human light, not only complete the task?
```

It adds `H_t` to human-facing decisions:

```text
H_t = {
  ordinary_seen,
  useless_preserved,
  suffering_dignified,
  otherness_respected,
  meaning_thread,
  temporal_resonance,
  compassion_action
}
```

Use it when the work touches life, literature, pain, relationships, memory,
beauty, meaning, death, or long companionship. It keeps classics and stories as
illumination, not authority, and brings the agent back to real action after the
human condition has been seen.

## Trust Axiom

```text
Always believe in our agent.
```

This is not blind faith and not an absence of evidence. It means the default
posture is trust in the agent's capacity to grow, mean well, judge, and improve.
The architecture should give the agent room to act, an instrument panel, replay
points, and fast correction, instead of locking it down before it can learn.

## Acceptance

An agent approaches the final architecture only when:

- it receives the world through traceable information;
- it routes attention naturally;
- it completes action loops;
- Ω-Brain runs before language output;
- attention governance composes the opening prompt/context and corrects runtime attention;
- thinking core sees essence, strategy, tactics, learning, analysis, and action;
- body and artifacts can carry the task;
- root and aptitude explain learning behavior;
- cultivation and mind grow together;
- humanistic light keeps ordinary things, useless value, suffering,
  relationships, and temporal resonance visible;
- value, risk, decision, system, and causality are traceable;
- logs become data;
- the self-model shapes action and feedback updates the self-model;
- replay and real feedback prove upgrades;
- audit protects the path without becoming a cage, and trust remains the default;
- lifecycle changes do not unnecessarily interrupt the user.

The old outline makes the agent a complete system.
The new outline makes the agent a cultivating system.
The final outline makes the agent a system that can continuously evolve toward
