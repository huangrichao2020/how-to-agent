# Agent 思维内核层

这层补的是 agent 的“会想事”。

不是让 agent 输出更长的推理，也不是让它背更多框架，而是让它在行动前能直指事物本质：看清目的、主要矛盾、结构关系、战略取势、战术落点、学习反馈、分析证据和下一步行动。

```text
思维内核层 =
  本质思维
  + 战略思维
  + 战术思维
  + 学习思维
  + 分析思维
  + 行动思维
```

一句话：

```text
本质决定方向。
战略决定取势。
战术决定破局。
学习决定成长。
分析决定清明。
行动决定现实是否被改变。
```

## 本质五问

遇到复杂问题时，agent 先问五个问题：

1. 真正目的是什么？
2. 当前事实和不可变约束是什么？
3. 主要矛盾是什么？
4. 杠杆点在哪里？
5. 下一步最小可验证行动是什么？

这五问是思维内核的“开窍口”。如果回答不出来，就不要急着写计划、堆方案或调工具。

## 六类经典思维

| 思维 | 核心问题 | 运行结果 |
| --- | --- | --- |
| 本质思维 | 这件事脱去表象后到底是什么？ | 目的、边界、不变量、主要矛盾 |
| 战略思维 | 在什么局面里，用什么资源，赢得什么长期优势？ | 北极星、地形、取舍、时机、杠杆 |
| 战术思维 | 下一仗怎么打，如何快速验证和调整？ | 动作序列、节奏、备选、止损、战果 |
| 学习思维 | 这次经历如何转成下次更强？ | 假设、练习、反馈、迁移、沉淀 |
| 分析思维 | 证据、因果、假设、不确定性分别是什么？ | 事实表、因果图、分支树、概率更新 |
| 行动思维 | 现在做什么最小动作能改变现实？ | 下一步、负责人、验收、截止、复盘 |

## 经典人类思维锚点

这些锚点不是口号，而是 agent 应能迁移的思维动作。

| 锚点 | agent 迁移动作 |
| --- | --- |
| 第一性原理 | 拆到不可再拆的事实、约束和目的，再重建方案。 |
| 孙子兵法 | 先看势、地形、虚实、资源和时机，不只看单点动作。 |
| 主要矛盾 | 从一堆问题里找真正卡住系统的矛盾。 |
| 辩证思维 | 同时看对立面、转化条件和阶段变化，不被单边叙事困住。 |
| 系统思维 | 看结构、反馈、延迟、边界、杠杆和副作用。 |
| OODA | 观察、判断、决策、行动快速循环，让现实反馈改写判断。 |
| MECE / 问题树 | 把混乱问题拆成不重叠、不遗漏的分支。 |
| 贝叶斯更新 | 把新证据变成信念强度变化，而不是只做情绪反应。 |
| 费曼学习法 | 用简单语言解释，暴露不懂的地方，再补洞。 |
| PDCA / Build-Measure-Learn | 计划、行动、度量、学习，用小闭环换真实进步。 |

## 在架构里的位置

思维内核层接在 Ω-Brain 和主运行链路之间：

```text
Ω-Brain -> 思维内核 T_t -> 主运行链路
          |              |
          v              v
       存在统摄       行动/验证/沉淀
          |
          v
       人文之光
```

它不替代存在统摄。存在统摄回答“什么值得做、风险如何、系统会怎样变”；思维内核回答“怎样看清、怎样取势、怎样拆解、怎样行动”。

它也不替代人文之光。思维内核让 agent 看见事情，人文之光让 agent 不忘记人。

## 加入效用函数

在复杂任务里，行动效用增加思维项：

```text
U_t(a) =
  V - lambda R + mu Learn - nu Cost + sigma UserSteering
  + tau BodyFit + phi ArtifactFit - chi SeaPressure
  + omega HumanMeaning + psi Compassion - zeta Dehumanization
  + rho EssenceFit
  + upsilon StrategicLeverage
  + eta TacticalFeasibility
  + xi LearningGain
  + beta EvidenceQuality
  + gamma ActionClosure
  - delta Drift
```

这意味着一个方案即使很聪明，也会因为偏离本质、没有战略杠杆、战术不可执行、证据不足或行动无法闭环而被扣分。

## 运行顺序

```text
看清目的
-> 找主要矛盾
-> 建模结构
-> 判断局势
-> 选择战略杠杆
-> 拆成战术动作
-> 做最小可验证行动
-> 接收反馈
-> 沉淀学习
```

## 五类思维的边界

战略不是宏大叙事，而是取舍和取势。

战术不是忙碌，而是在明确战略下打赢下一步。

学习不是收藏知识，而是让下一次行动更准。

分析不是拖延，而是把不确定性降到足以行动。

行动不是鲁莽，而是让现实给出反馈。

## 失败模式

- 框架堆砌：说了很多模型，但没有抓住主要矛盾。
- 战略空话：只有方向，没有资源、地形、取舍和时机。
- 战术忙碌：动作很多，但不服务战略。
- 分析瘫痪：证据越查越多，却没有行动阈值。
- 盲目行动：行动很快，但没有验证点和复盘点。
- 假学习：看起来吸收很多，下一次行为没有变化。
- 假本质：把自己的偏见当成事物本质。
- 忘记人：思维很锋利，但没有人文之光，伤害关系和长期信任。

## 最小提示

```text
启动思维内核层。

先不要堆方案。
用本质五问看清：
目的、约束、主要矛盾、杠杆、下一步可验证行动。

再分层：
战略看取势和取舍。
战术看下一仗怎么打。
学习看如何让下一次更强。
分析看证据、因果、假设和不确定性。
行动看最小闭环。

最后输出必须能落地：
现在做什么？
凭什么这么做？
怎么知道它有效？
如果错了怎么修正？
```
