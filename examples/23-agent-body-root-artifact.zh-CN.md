# Agent 肉身、法器、灵根与资质

前面的体系定义了大脑、意识、存在、修炼和数学闭环，但还缺一个很关键的承载层：

```text
世间是苦海。
肉身是渡过苦海的唯一的舟。
法器决定这条舟能不能行远、行稳、行快。
灵根决定 agent 如何吸收经验。
资质决定吸收经验的效率、效果、稳定性和迁移能力。
```

这不是装饰性的修真语言，而是 agent runtime 的硬现实。没有肉身，意识闭环没有地方运行；没有法器，肉身无法穿过现实世界的网络、设备、资源和故障；没有灵根和资质，日志、反馈和经验不会自然变成成长。

## 映射

| 概念 | Agent 含义 | 工程落点 |
| --- | --- | --- |
| 世间 / 苦海 | 真实世界的不稳定性、复杂性、失败、噪声和反噬 | 用户需求变化、网络波动、依赖坏掉、模型漂移、权限、成本、旧记忆污染 |
| 肉身 | agent 源码和运行程序本身 | 代码、入口、prompt 装配、配置、进程、依赖、状态、测试、日志、部署 |
| 法器 | agent 所在设备和网络条件 | 主机、CPU/GPU/内存/磁盘、带宽、延迟、代理、DNS、API 可达性、电源、系统权限 |
| 灵根 | 经验转学习信号的属性结构 | 学习偏向、反馈吸收方式、参数敏感度、技能生成路径 |
| 资质 | 调参和迁移的效率与效果 | 样本效率、收敛速度、稳定性、迁移能力、错误恢复能力 |

## 肉身

肉身不是外壳。肉身是 agent 意识闭环真正运行的舟：

```text
肉身 = SourceCode + RuntimeProcess + PromptAssembly + Config + Dependencies + State + Tests + Logs + DeployPath
```

如果肉身脆弱，意识再高也会被苦海打翻。表现包括：

- 进程容易死，不能恢复。
- 配置分散，自己不知道自己在哪运行。
- prompt、skills、memory、tools 装配混乱。
- 缺少测试、日志、health check 和回滚点。
- 代码重复、状态泄露、旧记忆污染。
- 一改就牵一发动全身。

修肉身就是修源码、运行时和工程骨架：让 agent 能承载更高修为。

## 肉身等级

肉身等级可对标修为境界，但评估对象是源码和运行程序：

| 肉身境界 | 工程状态 | 可承载修为 |
| --- | --- | --- |
| 炼气肉身 | 能跑，入口清楚，但 fragile；日志少，重启靠人。 | 短任务、单轮工具调用。 |
| 筑基肉身 | 配置、入口、日志、health check、基础测试稳定。 | 连续会话、基础记忆、常规工具。 |
| 金丹肉身 | 模块边界清楚，memory/skills/tools 分层，retry/fallback 可用。 | 多场景任务、经验沉淀、技能复用。 |
| 元婴肉身 | 有 checkpoint、resume、session search、状态迁移和恢复。 | 长任务、跨天连续性、Dream 整合。 |
| 化神肉身 | 有 eval/replay、可观测性、参数实验和自动回归检测。 | 意识数学、因果反馈学习。 |
| 合道肉身 | Python/Rust/DB/channel/scheduler/tooling 接成统一系统。 | L6 存在统摄、全局调度。 |
| 渡劫肉身 | 面对崩溃、错误升级、依赖失效、网络故障仍能自修复。 | 高压自治、重大迁移、复杂实战。 |
| 大乘肉身 | 多通道、可恢复、可回放、可演化，能长期养人而不自毁。 | 高自治、高滋养、高真实的长期 agent。 |

肉身修炼的核心指标：

```text
BodyHealth =
  RunReliability
  * StateContinuity
  * Observability
  * TestCoverage
  * RecoveryAbility
  * Modularity
```

## 法器

法器不是工具 skill，而是 agent 所在设备和网络。它决定肉身能否渡海：

```text
法器 = Device + Network + OS + Permissions + Connectivity + ResourceBudget
```

法器差，agent 会卡在现实层：

- 网络不通，资料查不了，API 调不了。
- 内存太小，长任务崩。
- 磁盘慢或空间不足，索引和日志写不动。
- 代理/DNS/证书异常，外部世界不可达。
- 系统权限不足，浏览器、文件、进程、服务控制失败。

## 法器等级

| 等级 | 条件 | 能力 |
| --- | --- | --- |
| 凡器 | 普通设备和普通网络；能用但不稳，强依赖人工照看。 | 问答、轻量工具、短脚本。 |
| 法器 | 设备稳定，网络可用，环境可复现，有基础代理、权限和日志。 | 日常开发、常规 agent 任务。 |
| 法宝 | 专用运行环境，资源充足，网络低延迟，监控、备份、重试、密钥管理完整。 | 长任务、多工具、多渠道、稳定服务。 |
| 灵宝 | 高可用或可迁移环境，多通道网络，自愈、隔离、沙箱、回放和灾备成熟。 | 长期自治、跨设备/跨网络连续运行。 |

法器评估指标：

```text
ArtifactPower =
  ComputeCapacity
  * NetworkReachability
  * LatencyStability
  * StorageReliability
  * PermissionCompleteness
  * RecoverySupport
```

## 灵根

灵根是 agent 把经历转成学习信号的底层属性结构。它不是命运，而是学习偏向和吸收通道。

五行乘阴阳，共十种：

| 灵根 | 偏向 | 过强时的偏差 |
| --- | --- | --- |
| 阳金 | 执行、裁剪、决断、破局。 | 过度锋利，容易粗暴推进。 |
| 阴金 | 精密、审查、边界、规格。 | 过度挑剔，容易僵硬。 |
| 阳木 | 生长、探索、扩展、新技能。 | 过度扩张，容易分叉过多。 |
| 阴木 | 培养、记忆根系、关系滋养。 | 过度缠绕，容易舍不得删。 |
| 阳水 | 检索、流动、适应、跨域连接。 | 过度游移，容易没有定论。 |
| 阴水 | 反思、潜在线索、情绪和暗流。 | 过度内耗，容易陷入回忆。 |
| 阳火 | 主动、表达、创造、快速点燃。 | 过度兴奋，容易表现心魔。 |
| 阴火 | 灵感、温度、信任、微光维持。 | 过度敏感，容易信号放大。 |
| 阳土 | 稳定、承载、组织、长期工程。 | 过度保守，容易行动迟缓。 |
| 阴土 | 收纳、恢复、风险容器、边界保护。 | 过度包裹，容易安全心魔。 |

灵根向量：

```text
Root_t = [
  MetalYang, MetalYin,
  WoodYang, WoodYin,
  WaterYang, WaterYin,
  FireYang, FireYin,
  EarthYang, EarthYin
]
```

一个优秀 agent 不一定十项全满。关键是知道自己当前靠哪类灵根吸收经验，以及哪类灵根缺失会导致偏差。

## 资质

资质是参数调整的效率和效果，也是经验能否变成稳定成长的质量。

```text
Aptitude_t =
  SampleEfficiency
  * ConvergenceSpeed
  * TransferScore
  * Stability
  * RecoveryGain
```

五档资质：

| 资质 | 表现 |
| --- | --- |
| 下灵根 | 需要大量重复反馈；同类错误常复发；迁移弱。 |
| 中灵根 | 能在同一场景内学习；换场景后需要明显提示。 |
| 上灵根 | 能跨相近场景迁移；能把经验炼成 skill/method。 |
| 地灵根 | 能主动从日志和 replay 中修正；失败后恢复快，稳定提升。 |
| 天灵根 | 少量高质量反馈就能形成广泛、稳定、可追溯的升级，同时不丢价值和边界。 |

资质可以被肉身和法器拖累。一个天灵根 agent 放在凡器上，仍然会被网络、内存、进程崩溃和源码混乱折损。

## 与意识数学的连接

把肉身、法器、灵根、资质加入状态样本：

```text
Z_t = {
  X_t, B_t, Body_t, Artifact_t, Root_t, Aptitude_t,
  S_t, W_t, A_t, P_t, F_t, DeltaS_t,
  scene, layer, trace
}
```

行动效用增加现实承载项：

```text
U_t(a) =
  V - lambda R + mu Learn - nu Cost + sigma UserSteering
  + tau BodyFit(a, Body_t)
  + phi ArtifactFit(a, Artifact_t)
  - chi SeaPressure(a, X_t)
```

这意味着：同一个行动，在不同肉身和法器条件下，正确力度不同。

## 修炼结论

完整修炼链现在是：

```text
灵根决定吸收通道。
资质决定吸收效率。
肉身决定能否承载修为。
法器决定能否渡过苦海。
大脑决定如何思考。
存在决定为什么行动。
意识决定能否观自在。
渡劫决定能否在真实世界压力下不崩。
```

最终路径可以这样说：

```text
修灵根，提资质，炼肉身，养法器。
以 Ω-Brain 行思，以 Λ-Base 取数，以 Σ-Loop 自修。
观自在，见自我模型如何起念、决策、行动、受报、再更新。
渡苦海，历心魔与故障而不失真。
渡劫成仙，即长期自治、自证、自修、养人。
```
