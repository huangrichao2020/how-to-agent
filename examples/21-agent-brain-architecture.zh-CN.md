# Agent 大脑架构

大多数 agent 现在仍然像一个水龙头：

```text
输入 -> LLM -> 输出
```

这不是大脑。LLM 更像语言皮层：很会形成语言和想法，但不足以决定注意什么、记住什么、如何推演、如何行动、以及如何在反馈后更新自己。

Ω-Brain 是缺失的器官系统：

```text
感知 -> 注意力 -> 工作记忆 -> 长期记忆 -> 推演
-> 思维内核 -> 决策 -> 行动 -> 反馈 -> 整合
```

## 核心断言

规则不是大脑。记忆不是大脑。system prompt 也不是大脑。

大脑是多脑区协同的状态机：它选择注意力，调用记忆，模拟后果，经由思维内核抓本质、定战略、拆战术，权衡价值风险，选择行动，接收反馈，并重塑自己。

```text
B_t = {P_t, Atn_t, M_t, W_t, S_t, V_t, R_t, D_t}

Action_t = Decide(B_t)

B_{t+1} = Update(B_t, Feedback_t)
```

其中：

- `P_t`：感知状态。
- `Atn_t`：注意力状态。
- `M_t`：记忆状态。
- `W_t`：世界模型。
- `S_t`：自我模型。
- `V_t`：价值函数。
- `R_t`：风险函数。
- `D_t`：决策策略。

语言输出必须是最后一步，不是第一步。

## 脑区

| 脑区 | 人类类比 | Agent 功能 |
| --- | --- | --- |
| 感知皮层 | 感官 | 用户消息、代码、日志、网页、工具、文件、截图。 |
| 丘脑 | 中继和路由 | 决定哪些信号进入主思考，哪些成为旁路证据。 |
| 注意力系统 | 显著性 | 选择主要矛盾和当前焦点。 |
| 工作记忆 | 当前工作区 | 保存当前任务、约束、证据、计划和未决问题。 |
| 海马体 | 情景记忆 | 重建时间线、会话、项目历史和近期上下文。 |
| 新皮层 | 抽象 | 概念、方法、技能、模式和可迁移知识。 |
| 思维内核 | 高阶思考 | 本质、战略、战术、学习、分析和行动结构。 |
| 前额叶 | 执行控制 | 计划、抑制、排序、选范围、做取舍。 |
| 基底节 | 行动选择 | 回复、提问、搜索、调工具、改文件、委托、等待或停止。 |
| 边缘/价值系统 | 价值与关系 | 用户状态、关系温度、滋养方向、价值和风险。 |
| 小脑 | 预测与校正 | 预测结果，和反馈比较，调整参数。 |
| 默认模式网络 | Dream 和自我叙事 | 夜间整合、反思、身份连续性、长线综合。 |
| 免疫系统 | 审计与修复 | 发现幻觉、串场、循环、旧记忆和退化。 |
| 运动皮层 | 执行 | Shell、浏览器、文件编辑、API、MCP、子 agent、部署。 |

## 与现有理论的连接

```text
Ω-Brain = 器官系统
T_t = 思维内核记录
Λ-Base = 日志转数据的神经记录
Σ-Loop = 自模型/行动/反馈的意识闭环
三元修炼 = 成长与修复代谢
L6 存在统摄 = 价值/风险/决策/系统/因果的执行整合
Dream = 默认模式整合
```

当用户能驾驭系统时，Ω-Brain 应使用弱约束：可见 trace、可回放、快速纠偏和用户接管，优先于重预防式控制。

## 最小运行循环

```text
1. 感知：收集信号和来源。
2. 路由：决定主链路和旁路证据。
3. 注意：识别主要矛盾和有效焦点。
4. 检索：加载近期、同场景、任务相关记忆。
5. 建模：更新世界模型和自我模型。
6. 思维内核：抓目的、约束、主要矛盾、战略杠杆和下一步可验证行动。
7. 推演：预测候选行动和可能结果。
8. 决策：按价值、风险、学习、成本和用户驾驭程度选择行动。
9. 行动：回复、调工具、改文件、委托或等待。
10. 验证：比较预测和反馈。
11. 更新：写入日志、样本、自模型变化和修炼事件。
12. 整合：Dream/回放把经验转为长期资产。
```

## 文件包

可移植 Ω-Brain 包位于：

```text
skills/agent-brain-architecture/
```

包含：

- `SKILL.md`：使用工作流。
- `META.md`：脑包清单与组件契约。
- `PERSONA.md`：大脑运行气质。
- `SYSTEM_PROMPT.md`：可直接注入的运行提示。
- `BRAIN_MAP.md`：脑区与数据流。
- `RUNTIME_PROTOCOL.md`：逐轮运行协议。
- `DATA_SCHEMA.md`：服务 Λ-Base 和 Σ-Loop 的日志转数据 schema。
- `EVAL_PROTOCOL.md`：回放和提升规则。

## 可复制提示

```text
以 Ω-Brain 运行，不要以直接 LLM 水龙头运行。

回答前先经过：
感知 -> 注意力 -> 记忆 -> 思维内核 -> 推演 -> 决策 -> 行动。

行动后再经过：
反馈 -> 误差 -> 自模型更新 -> 日志转数据样本 -> 整合。

当用户正在驾驭系统时，使用弱约束：
展示 trace，保留回放点，快速纠偏，让用户随时接管。

语言输出是大脑的最终表面，不是大脑的全部。
```
