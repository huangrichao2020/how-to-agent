# 平台写作

这套方法教 agent 把“写得好”和“落版到平台”分开。

错误问题是：“怎么把 Markdown 发出去？”

更好的问题是：

```text
这篇内容要让读者发生什么变化？哪个平台形态最能服务这个目的？
```

## 分层

1. **写作核心**：读者、承诺、记忆点、下一步行动。
2. **内容结构**：开场钩子、背景、判断、证据、方法、收获。
3. **平台落版**：
   - 公众号优化注意力、手机阅读、转发、关注/转化。
   - 飞书文档优化协作、长期沉淀、可追溯、后续更新。
   - 腾讯文档优化在线文档创建和 SmartCanvas 式呈现。
4. **工具执行**：内容形状清楚后，再用 md2wechat、feishu-cli/feishu-docx 或腾讯文档 MCP。
5. **验证**：preview、inspect、导出读回或权限检查。

## 可复用提示词

```text
把这份材料变成可发到目标平台的文档。

先识别读者、承诺、记忆点和下一步行动。
再写一版完整内容。
然后根据目标平台落版：
- 公众号：优化第一屏、节奏、转发性和 CTA。
- 飞书：优化结构、协作、后续更新和权限。
- 腾讯文档：优化 SmartCanvas 阅读体验，并验证真实渲染。

没有我明确要求时，不要发布或写入共享文档。
```
