# A股定时分析报告任务模板

用于快速部署或更新 A 股盘前、午评、收盘复盘的定时推送任务。所有报告严格遵循用户的股票宪法。

## 🕘 盘前策略 (08:45)
- **Schedule**: `45 8 * * 1-5`
- **Target**: 飞书
- **Skills**: `stock-trading-desk`

**Prompt**: 
```
现在是北京时间早上，用户醒来需要一份A股盘前策略简报。

执行以下步骤：
1. 搜索隔夜外盘表现（美股三大指数、纳斯达克金龙中国指数、A50期货）
2. 搜索今日A股重要公告、政策新闻、行业催化事件
3. 搜索近期市场主线板块、连板梯队情况

然后用【人性/执念/住相/供需】方法论输出盘前分析：

【隔夜外盘与情绪传导】
- 美股/中概股/A50表现
- 对今日A股情绪传导方向

【今日催化事件扫描】
- 重要政策/行业新闻/公司公告
- 评估：哪个事件可能点燃人群执念？

【执念阶段判断】
- 当前市场主线是什么？处于哪个阶段（启动/发酵/高潮/退潮）？
- 谁的执念？（机构/游资/散户/北向）
- 需求增加还是供给增加？
- 龙头是否继续领涨？

【今日策略预判】
- 阻力最小方向判断
- 可关注板块/方向（只做前排和确认，不做后排和尾声）
- 风险提示

输出风格：简洁、实战导向，用"指挥单"口径，直接给判断。不超过500字。
```

## 🕦 午评 (11:35)
- **Schedule**: `35 11 * * 1-5`
- **Target**: 飞书
- **Skills**: `stock-trading-desk`

**Prompt**: 
```
现在是北京时间中午11:35，A股上午收盘。生成一份A股午评简报。

执行以下步骤：
1. 搜索今日上午A股行情（上证/深成/创业板涨跌幅、成交量、北向资金）
2. 搜索上午涨停/跌停板情况、连板梯队
3. 搜索上午领涨板块和领跌板块
4. 搜索上午市场重要新闻或盘中异动

然后用【人性/执念/住相/供需】方法论输出午评：

【上午盘面快照】
- 三大指数涨跌幅、成交量
- 北向资金流向（净流入/流出）

【执念阶段判断】
- 今天谁在领涨？龙头股表现如何？
- 执念在强化还是在松动？
- 供需关系：是需求驱动上涨还是获利盘兑现？

【板块强弱排名】
- 前排板块（资金主攻方向）
- 后排板块（跟风/退潮）

【下午策略预判】
- 阻力最小方向
- 需要重点关注的信号
- 风险提示

输出风格：简洁实战，用"指挥单"口径。不超过400字。
```

## 🕒 收盘复盘 (15:35)
- **Schedule**: `35 15 * * 1-5`
- **Target**: 飞书
- **Skills**: `stock-trading-desk`

**Prompt**: 
```
现在是北京时间下午15:35，A股已经收盘。生成一份A股收盘复盘简报。

执行以下步骤：
1. 搜索今日A股收盘行情（上证/深成/创业板涨跌幅、成交量、北向资金）
2. 搜索今日涨停/跌停板情况、连板梯队完整统计
3. 搜索今日板块涨跌幅排行
4. 搜索今日市场重要新闻、龙虎榜、大宗交易
5. 搜索盘后重要公告、政策

然后用【人性/执念/住相/供需】方法论输出收盘复盘：

【今日盘面总结】
- 三大指数涨跌幅、成交量（与昨日对比）
- 北向资金全天流向
- 涨跌家数比、涨停/跌停家数

【执念阶段复盘】
- 今天的主线是什么？处于哪个阶段（启动/发酵/高潮/退潮）？
- 龙头股表现（封板/炸板/跌停）
- 筹码交换：获利盘是在兑现还是继续锁仓？
- 住相是否出现破裂迹象？

【连板梯队与情绪周期】
- 最高板是哪只？几连板？
- 各高度连板数量
- 情绪温度计（冰点/回暖/高潮/退潮）

【明日策略预判】
- 明日阻力最小方向
- 今日资金主攻方向明日是否延续？
- 明日需要重点观察的信号
- 风险提示

输出风格：简洁实战，用"指挥单"口径。不超过500字。
```

## 部署注意事项
- 所有任务均设置为 `repeat: forever`。
- 确保目标飞书 ID 正确 (`deliver: feishu:<chat_id>`)。
- **盘中监控脚本**：在阿里云受限环境下，优先使用**腾讯行情接口** (`qt.gtimg.cn`)，避免东方财富接口限流。
- 如果用户要求调整频率或内容，直接修改对应 prompt 或 schedule。
