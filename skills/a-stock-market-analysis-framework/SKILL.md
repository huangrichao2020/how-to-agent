# A 股市场深度分析框架

## 核心理念

市场是人性的集合体。分析的核心不是预测涨跌，而是识别**「执念」**（资金共识）与**「供需」**（筹码结构）的错配。

**六爻行动映射**：每一个执念阶段，对应乾卦一爻。六爻不是一个预测工具，而是一个**认知-行动周期模型**——告诉你在这个阶段，你的人性执念是什么、应该做什么、不应该做什么。反复读反复学反复实践，道理才是真道理。

## Question-Form Mode (强制)

在盘前分析、盘后复盘、盘中异动分析时，**必须先锁定以下三要素，再给结论**。不得跳过直接拍脑袋。

| 要素 | 选项 | 说明 |
|------|------|------|
| **市场状态** | 主线行情 / 独立龙头行情 / 震荡防御 | 当前资金共识在哪 |
| **执念阶段** | 孕育→确认→高潮→分歧→退潮→冰点 | 六阶段中处于哪个（人性镜头） |
| **金融三级表** | 外资 / 机构 / 游资 / 散户 | 谁在动、谁在跑 |

## 分析五步法

### 0. 市场风格判断（新增前置层）

**在分析具体板块之前，先判断当前市场风格。** 风格决定策略，风格错了，选股再好也亏。

| 风格类型 | 核心特征 | 对应策略 |
|----------|----------|----------|
| **机构抱团大票** | 沪深300>国证2000，涨停<50家，连板2-3板，北向流入成长 | 趋势跟随，回踩均线买入 |
| **震荡低位轮动** | 指数横盘，涨停50-80家，板块快速切换，连板低 | 潜伏低吸，快进快出 |
| **抱团高标妖股** | 连板5板+，涨停>80家，小盘活跃，游资主导 | 打板龙头，断板即走 |

**资金倾向判断：**
- **进攻**：科技/新能源/军工/周期涨停占比高，北向流入成长股
- **防御**：银行/电力/高股息占优，北向流入红利股
- **均衡**：无明显偏向

**判断依据**（详见 [[market-style-judgment-methodology]]）：
1. 大小盘相对强度（沪深300 vs 国证2000涨跌幅）
2. 涨停家数及连板高度
3. 北向资金偏好（成长 vs 红利）
4. 连板晋级率 vs 炸板率

### 0. Question-Form 锁定 + 因果校验 (Causality Check)

在回答三个问题之前，先进行一次**因果性校验**。这是避免散户陷阱的核心机制。

| 要素 | 选项 | 说明 |
|------|------|------|
| **驱动因果** | 业绩超预期 / 政策突发 / 供需失衡 / 情绪跟风 / 无因 | **找到第三变量**。相关性不是买入理由，因果性才是。 |
| **市场状态** | 主线行情 / 独立龙头行情 / 震荡防御 | 当前资金共识在哪 |
| **执念阶段** | 孕育→确认→高潮→分歧→退潮→冰点 | 六阶段中处于哪个（人性镜头） |
| **金融三级表** | 外资 / 机构 / 游资 / 散户 | 谁在动、谁在跑 |

**因果判定原则**：
- **强因果**：业绩落地、政策驱动、产品涨价。**结论**：可重仓试错，持续性高。
- **弱因果（仅相关性）**：板块联动、跟风补涨。**结论**：放弃或极轻仓试错，随时撤退。
- **无因果**：无逻辑乱涨。**结论**：视为诱多（住相陷阱），绝不参与。

锁定以上四要素后，再进入下面的分析步骤。

### 1. 市场状态定性 (Market State)
*   **阶段判断**：是普涨期、分化期还是退潮期？
*   **情绪指标**：涨停数 vs 跌停数、连板高度、量能变化。
*   **核心矛盾**：当前资金在博弈什么？（如：财报暴雷恐惧 vs 涨价逻辑贪婪）

### 2. 主线供需拆解 (Supply & Demand)
对热点板块进行穿透：
*   **供给端**：是否有产能瓶颈、地缘政治限制、政策管控？
*   **需求端**：是否有真实业绩落地、技术迭代拉动？
*   **价格信号**：产品是否涨价？涨幅多少？持续性如何？
*   **定性**：
    *   **基本面共振**：有业绩 + 有涨价（最安全）。
    *   **情绪博弈**：纯故事 + 筹码战（高风险高收益）。

### 3. 龙头锚定 (Leader Anchor)
*   **识别龙头**：谁最先涨停？谁封单最硬？谁带动板块？
*   **反馈观察**：龙头断板时，板块是分歧转一致，还是直接 A 杀？
*   **操作建议**：只做龙头确认或低位补涨，严禁追高后排。

### 4. 动作指引 (Action Plan)
*   **进攻**：选择确定性最高的方向（如业绩超预期的 CCL）。
*   **防守**：配置高股息或避险资产（如石油、电力）。
*   **观察**：设定关键时间点（如 09:25 竞价、10:00 分歧点）。

## 双线作战框架（2026-05-14 升级）

**核心思想**：哲学翻译为可操作规则。短线看资金（执念博弈），中线看供需（拐点确认）。

### 📌 短线线（仓位70%）—— 执念博弈

| 规则 | 操作 |
|------|------|
| **选股** | 同花顺热点TOP3题材中，连板≥2或首板放量最强的 |
| **买入** | 分歧日买前排：龙头首次开板回封时进，或二板确认日进 |
| **卖出** | 断板即走：不连板、不放量、不反包，三不原则当日清仓 |
| **止损** | -5%硬止损 + 龙头跌停无条件砍 |
| **仓位** | 单票≤15%，同一题材最多2只 |

**短线铁律**：只做涨停梯队里的身位龙和补涨龙，不做跟风。身位断了就换，不恋战。

### 📌 中线线（仓位30%）—— 供需拐点

| 规则 | 操作 |
|------|------|
| **选股** | 涨价/政策/业绩三重共振：产品涨价+政策支持+业绩拐点 |
| **买入** | 放量突破20日线且板块同步走强时建底仓 |
| **加仓** | 回踩不破5日线加仓，每次加10% |
| **卖出** | 业绩证伪/政策转向/龙头断板三个信号出一个即减 |
| **止损** | 跌破20日线3日不收回清仓 |

**中线铁律**：中线票的短线化操作——用短线纪律管理中线仓位，破了就走，不扛单。

### 执行模板

```
早盘：看同花顺热点 → 找TOP3题材 → 锁定连板前排
盘中：龙头封板强度 → 决定跟不跟
尾盘：断板票清仓 → 新龙头确认进仓
盘后：更新六爻阶段判定 → 决定中线仓位加减
```

## 输出规范

*   **语态**：决策者语态。禁止“仅供参考”，结尾必须给出明确指令（如“按预案执行”）。
*   **结构**：结论先行 → 依据支撑 → 具体动作。
*   **避坑**：明确指出当前市场的“执念”陷阱（如：不要为了套利去买业绩差的低位股）。
