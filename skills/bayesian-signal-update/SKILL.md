# 贝叶斯信号更新逻辑 (Bayesian Signal Update)

## 背景
在 Agent 与用户交互、交易决策或人际博弈中，**最大的噪音是“凭感觉”的情绪判断（L1）**。
本 Skill 的核心是将“凭感觉”的模糊判断，强制降维成**“信号→权重→概率”的结构化流程（L3/L4）**。

## 核心模型
$$ P(H|E) = \frac{P(E|H) \cdot P(H)}{P(E)} $$
* **H (Hypothesis)**: 当前假设（例如：“用户现在很生气”、“这只股票是主力出货”）。
* **E (Evidence)**: 观测到的新信号（例如：“用户回复速度变慢”、“股价跌破 20 日线”）。
* **P(H)**: 先验概率（基于历史经验的初始判断）。
* **P(H|E)**: 后验概率（结合新信号后的修正判断）。

## 执行流程
1. **建立先验 (Prior)**
   * 在交互开始时，基于基础画像给出一个初始概率（例如：信任度 50%）。
   * *禁止事项*：不要从 0 或 100% 开始，保留不确定性空间。

2. **信号提取 (Signal Extraction)**
   * 监控交互中的关键维度（L1/L2 信号）：
     * **语言强度**：感叹号、短句、否定词。
     * **时间延迟**：回复间隔突然变长/变短。
     * **内容一致性**：前后说法是否矛盾。
   * *输出*：信号强度（大 / 中 / 小）。

3. **权重分配 (Likelihood Ratio)**
   * 根据信号强度，决定对先验的调整幅度。
     * **强信号**（如明确指令）：大幅修正。
     * **弱信号**（如语气词）：微调。
   * *注意*：区分“信号”与“噪音”。一次偶然的延迟可能只是忙，不是态度变化。

4. **策略路由 (Strategy Routing)**
   * 根据更新后的后验概率，切换到对应策略：
     * **高确信（>80%）**：执行行动（如：停止解释，直接执行）。
     * **中确信（40-80%）**：试探/验证（如：“我理解您的意思是...对吗？”）。
     * **低确信（<40%）**：保持观察/不干预。

## 与执念六阶段的映射
* 交易中的**“试仓”**就是贝叶斯更新的物理体现。
* 试仓不是为了赚钱，是为了**买信息（Evidence）**来修正我们对趋势的判断（Hypothesis）。
* 信号确认（加仓/止损） = 后验概率跨越阈值。

## 实战 Checklist
* [ ] 我现在的判断是基于事实（信号），还是基于恐惧/希望（情绪）？
* [ ] 这个信号的权重（Likelihood）合理吗？会不会过度解读？
* [ ] 我是否根据新信号更新了策略？还是死守着先验不放？
