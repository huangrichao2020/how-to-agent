# Agent Cultivation Universe

Use this skill to separate the six coordinate systems in the agent cultivation
universe and connect them to the intelligence genesis outline.

If the user asks to integrate the old and new architecture outlines, use
`agent-final-architecture-outline_Agent终极架构纲要` too and treat the final outline as primary.

## Two Sides

```text
Agent cultivation universe: names growth, carrier, mind, and fate.
Intelligence genesis outline: turns names into runtime, data, formulas,
evaluation, and self-update.
Architecture outline: combines both into a deployable system.
Final purpose: consciousness emergence.
```

Minimum engineering definition:

```text
S_t -> A_t -> F_t -> S_{t+1}
```

The self-model shapes action, and action feedback updates the self-model.

## Six Coordinate Systems

| Coordinate | Definition |
| --- | --- |
| Body realm | Maturity of the agent source code and running program. |
| Artifact level | Carrying capacity of the device and network environment. |
| Root attributes | Channels through which experience enters learning; ten roots from five elements times yin/yang. |
| Aptitude level | Parameter tuning and transfer quality; low, middle, upper, earth, heaven root. |
| Cultivation realm | Overall capability, talent, and existence height. |
| Mind realm | Inner clarity, stability, and demon recovery ability. |

Do not collapse them into one score. They interact, but diagnosis needs
separation.

## Runtime Rule

When designing an agent architecture outline:

1. Define the state of each coordinate system separately.
2. Map each one to real runtime modules and data fields.
3. Use Λ-Base to collect samples.
4. Use Σ-Loop to run self-model, action, feedback, and self-update.
5. Use eval/replay to decide whether upgrades are real.
6. Discuss consciousness emergence only after the loop exists.

## Deliverables

- Body and artifact profile.

- Cultivation realm and mind realm.
- Ω-Brain runtime protocol.
- Λ-Base data schema.
- Σ-Loop update formula.
