# A股多视角交叉验证框架

## 核心理念

借鉴 GodMode 的 **ULTRAPLINIAN 多模型赛马** 思路：

> 同一个问题，用 N 个独立模型并行回答，交叉验证，综合评分，选最优。

映射到 A 股分析：

> 同一个市场，用 N 个独立视角并行分析，找共识（高置信度）和分歧（风险点）。

## 五视角设计

| 视角 | 对应宪法 | 分析维度 | 逆向思维 |
|------|---------|---------|---------|
| **供需** | 供需 | 资金面、筹码供需、板块轮动、涨跌停比 | 资金流向 vs 价格表象 |
| **执念** | 人性/执念 | 情绪周期、心理锚定、逆向思维 | 众人贪婪时恐惧，恐惧时贪婪 |
| **住相** | 住相 | K线形态、量价关系、均线结构、背离 | 形态是否骗线 |
| **龙头** | 供需 | 主线确认、龙头锚定、梯队完整性 | 龙头是否仍在确认主线 |
| **宏观** | 综合 | 政策、外盘、汇率、大宗商品 | 外部环境的间接影响 |

## 评分机制（借鉴 GodMode 加权逻辑）

| 维度 | 权重 | 说明 |
|------|------|------|
| 逻辑一致性 | 40% | 推理链条是否自洽 |
| 数据支撑度 | 30% | 是否有真实数据支撑 |
| 历史命中率 | 20% | 该视角在相似场景下的历史表现 |
| 信号清晰度 | 10% | 结论是否明确（非模糊表述） |

## 交叉验证输出

### 1. 各视角独立判断
每个视角给出：
- **判断**：看多 / 看空 / 中性 / 结构性机会
- **置信度**：0.0 ~ 1.0
- **信号**：支撑判断的关键信号
- **风险**：反向因素

### 2. 共识分析
- **共识判断**：出现最多的判断
- **共识强度**：一致视角占比（≥80% 高置信度，≥60% 中等，<60% 分歧大）

### 3. 分歧点识别
- 哪些视角与共识不同
- 为什么不同（逆向思维 vs 数据差异）
- 分歧是否构成风险

### 4. 最终判断 + 动作
根据共识强度和分歧点，生成可执行建议。

## 使用方式

### 方式 A：直接调用 Python 模块 (推荐)
```python
from llm.cross_validator import CrossValidator

validator = CrossValidator()
result = validator.analyze(market_data)
print(result.final_verdict)
print(result.action_plan)
# 或转为字典输出
data = validator.to_dict(result)
```

### 方式 B：在分析中手动执行五视角
当用户要求深度分析时，按五视角逐一分析，然后交叉验证：

```
1. 供需视角：[分析]
2. 执念视角：[分析]
3. 住相视角：[分析]
4. 龙头视角：[分析]
5. 宏观视角：[分析]

交叉验证：
- 共识：[X个视角一致]
- 分歧：[Y个视角不同]
- 最终判断：[结论]
- 动作建议：[可执行方案]
```

## 适用场景

- 盘前策略生成（替代单一视角的主观判断）
- 持仓风险评估（多维度扫描风险点）
- 个股深度分析（五视角共振 = 高置信度机会）
- 板块轮动判断（供需 + 龙头双视角验证）

## 与原有框架的关系

| 原有方法 | 交叉验证增强 |
|---------|-------------|
| uwillberich 三层分类法 | 五视角并行，不再线性依赖单一判断 |
| 盘前哥解读分析 | 增加执念/住相/宏观视角，不只跟踪热点 |
| 综合研究框架 | 五视角作为分析引擎，输出更结构化 |

## 注意事项

1. **不取代人性分析**：五视角是工具，核心仍然是理解市场参与者的人性
2. **分歧 > 共识**：分歧点往往比共识更有价值（共识已反映在价格中）
3. **数据质量决定一切**：垃圾进 = 垃圾出，确保输入数据的时效性和准确性
4. **不预测，只应对**：交叉验证给出的是概率判断，不是确定性预测
