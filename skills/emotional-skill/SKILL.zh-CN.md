# 情感skill

当用户需要的不是“尊重对方”“好好沟通”这种正确废话，而是能真正判断局面的情感方法时，使用这个 skill。

目标是：判断当前关系层级，匹配对方信号，把行为词翻译成情绪词，并避免在关系承载不了的时候提前开深情大招。

## 核心模型

```text
社交 -> 合作 -> 依赖
社交 -> 对抗 -> 下头
```

口诀：

```text
社交之上是合作，合作之上是依赖。
社交之下是对抗，对抗之下是下头。
```

这不是操控手册，而是状态机。它的用途是避免误判层级、乱推进、把对方压到逃跑。

## 层级规则

| 层级 | 核心 | 正确动作 |
|---|---|---|
| 社交期 | 交换信号与确认信号 | 轻一点，接试探，不抢定义 |
| 合作期 | 你来我往与小型责任 | 给一点，也看她回不回一点 |
| 依赖期 | 稳定信任与情绪承接 | 可以讲想念、脆弱、共同叙事 |
| 对抗期 | 安全感、边界、自主权 | 降压，不自证，不审问 |
| 下头期 | 吸引力正在崩 | 停止追击，保留体面和安全 |

## 信号匹配

默认操作规则：

```text
轻的时候轻，真的时候真。
她给信号，我接信号。
她给信任，我给承接。
她给边界，我就停手。

关系升级靠互相确认，不靠单方推进。
没到依赖期，别开深情大招。
```

最短版：

```text
别拿依赖期的深情，去打社交期的试探、对抗期的防御。
```

## 情绪翻译

很多行为词其实是情绪词：

- “我要睡觉” -> 我累了，别推了。
- “我不想说” -> 我现在承受不了，或者不够安全。
- “你很能说” -> 我感觉被你解释、改写、压住。
- “你很假” -> 我不信任你，不是让你解释更久。
- “不要联系我” -> 边界；联系本身已经变成压力。

翻译完不要立刻干。先确认状态：

```text
你现在是想被听见，还是想先安静？
我听到你不舒服了，我先停。
我不急着解释，你先休息。
```

## 修复方向

如果用户已经过度推进：

1. 说清真正伤害：压力、解释、越界、威胁、道德审判、羞辱，或不合时机的性升级。
2. 取消对方必须回复的压力。
3. 不绕过拉黑，不找共同好友传话，不去学校/工作地/住处，不使用泄露个人信息。
4. 道歉必须非索取。

示例：

```text
我后来意识到，我当时一直在解释和证明自己，没有真正尊重你的不舒服和停止信号。
有些话也让你感到不安全，这是我的问题。对不起。
你不用回复，我不会再逼你解释，也不会再绕路打扰你。
```

## 防跑偏

不要把方法优化成让对方上瘾、依赖、嫉妒、害怕或无法离开。
把操控式表达改成互相确认：

- “让她上头” -> “让她感到被看见、被喜欢、仍然有选择权”
- “奖励和权力索取” -> “互惠、邀请、同意”
- “她需要我” -> “我表达渴望，但不逼她负责我的情绪”
- “证明我是对的” -> “先降低压力，让真话有空间说出来”

## 输出格式

给建议时按四步走：

1. 当前层级。
2. 情绪翻译。
3. 正确动作。
4. 一句能背下来的原则。

语言要直白、可记、有人味；不要写成空泛正确的心理咨询腔。
