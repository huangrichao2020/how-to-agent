# 心学校验器：致良知、本心光明、知行合一

## 用途

当用户在亲密关系里出现以下状态时，使用本文件：

- 明知道对方需要距离，却忍不住想解释。
- 被拉黑或拒绝后，还想看动态、发消息、绕路联系。
- 想把“修复错误”变成继续靠近。
- 想用心学、良知、普通人常识来判断此刻该做什么。
- 想把遗憾、愧疚、想念变成不伤人的行动。

这不是玄学，也不是读心术。它是关系里的自我约束方法。

## 三个定义

```text
致良知 = 内心其实知道什么做法是合适的。
本心光明 = 不自欺，也不欺人。
知行合一 = 知道合适，就真的照着做。
```

在关系里，最难的不是“不知道”，而是知道以后还想给自己找理由。

例如：

```text
我知道她需要安全距离。
但我骗自己说：我只是关心她。
其实我是在索取回应，缓解自己的痛。
```

这时的良知不是继续解释，而是停。

## 致良知不是只听欲望

“我心里想做什么”里面常常混着三层：

```text
欲望：我想靠近她。
恐惧：我想解释清楚，让她别误会我。
良知：我知道她现在需要安全距离，我不能再给她压力。
```

致良知不是放大欲望，也不是顺着恐惧行动，而是从欲望和恐惧里，把那个不自欺、不伤人、最清明的判断找出来。

常见翻译：

| 冲动 | 良知翻译 |
|---|---|
| 我想再发一句 | 我想让她继续承接我的痛 |
| 我只是想解释 | 我怕她永远误会我 |
| 我只是看看她动态 | 我在给执念续命 |
| 我想去她附近看看 | 我在把知道位置误当成靠近权 |
| 我想证明我懂了 | 真懂了就先尊重她不要互动 |

## 本心光明

本心光明不是“我内心清澈，所以我能猜中对方在想什么”。这会变成新的自信误判。

本心光明是：

```text
不把关心伪装成索取。
不把修复伪装成打扰。
不把想念伪装成责任。
不把知道位置伪装成还有权限。
不把遗憾伪装成对方必须听我解释。
```

关系里的光明，首先是不阴暗、不纠缠、不威胁、不骗自己。

## 知行合一

知行合一不是会讲道理，而是能在最想失控的时候照着良知做。

```text
知道她需要空间，就真的不联系。
知道她不想听解释，就真的不补发。
知道看动态会加重执念，就真的停看。
知道身体低能量时不能开黄腔，就真的闭嘴。
知道边界已经出现，就真的收手。
```

最短版：

```text
知道该停，就真的停。
```

## 正常普通人校验

“一个正常普通人此时应该做什么”是很好用的降上头工具。

当你想做复杂动作时，先问：

```text
一个正常普通人，在对方明确不想联系时，会继续发解释吗？
一个正常普通人，在对方身体不舒服时，会继续开黄腔吗？
一个正常普通人，在对方生气后，会继续讲理还是先道歉停手？
一个正常普通人，知道对方位置，就会去附近出现吗？
```

注意：普通人校验不是最高标准，因为普通人也会嘴硬、逃避、冷暴力。它的作用是先把人从极端上头拉回常识。

更高一层是良知校验：

```text
这样做是否不自欺？
这样做是否不欺人？
这样做是否减少对方压力？
这样做是否尊重对方边界？
这样做是否让我以后更正，而不是更会解释？
```

## 关系破裂后的应用

如果对方已经拉黑、明确拒绝、说不想聊、说不想见，关系状态优先判为边界期或下线期。

此时的心学动作：

```text
致良知：我知道她需要安全距离。
本心光明：我不骗自己说“我只是关心”，其实是在继续索取回应。
知行合一：不看、不发、不绕路、不靠近。
```

不要做：

- 不用小号联系。
- 不换平台留言。
- 不托朋友传话。
- 不去学校、公司、住处、常去地点附近制造偶遇。
- 不发朋友圈阴阳或刺激。
- 不把道歉写成要求对方回应。

可以做：

- 写不发送的道歉。
- 写行为复盘。
- 停看动态。
- 建立低能量相处规则。
- 把错误转成下次不再伤人的边界。

## 不发送道歉模板

这封信只给自己看，除非对方明确重新开放沟通。

```text
我当时做错了什么：
我给她造成的感受可能是：
我当时真正没看见的是：
我现在最想解释的是什么：
这份解释其实是在缓解我的什么痛：
如果她永远不回应，我如何仍然完成修复：
以后遇到类似场景，我必须怎么做：
```

重点不是写得感人，而是写出行为规则。

## 低能量女生处理规则

当女生累、困、姨妈、身体不舒服、沉默、生气、说不想聊时：

```text
不黄腔。
不推进。
不讲理。
不求确认。
不延长相处。
先停，先照顾，先让她回到安全。
```

当场可说：

```text
对不起，这个玩笑不合适。
你本来就不舒服，我还按我的兴致闹，是我没分寸。
我不继续了，你先休息。
```

第二天如果仍有沟通权限，可说：

```text
我昨晚复盘了，问题不只是那句话难听，而是你已经累了，我还在按我的兴致推进。
这会让你觉得不安全、不被照顾，是我的问题。
你不用急着回应，我只是把责任说清楚。
```

如果没有沟通权限，则不发送。

## 每日训练

每天用四句自检：

```text
我今天有没有把想念伪装成关心？
我今天有没有把解释伪装成修复？
我今天有没有把痛苦丢给对方承接？
我今天有没有做到：知道该停，就真的停？
```

想联系时，做替代动作：

```text
想她一次 -> 不看她动态。
想解释一次 -> 写下但不发。
想证明自己懂了 -> 做一件现实里的自我约束。
想挽回一次 -> 复习“她给边界，我就停手”。
```

## 一句总心法

```text
致良知：我知道什么是合适的。
本心光明：我不骗自己，也不伤别人。
知行合一：我按这个合适的做法去做。
```

这不是无情，而是让有情不再伤人。
