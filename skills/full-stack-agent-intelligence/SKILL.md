# Full-Stack Agent Intelligence

Use this skill when improving the whole intelligence architecture of a long-running agent such as GA, Hermes, or Codex.

## Map

```text
information -> scheduling -> loop -> output stream

memory architecture -> cognition architecture -> evolution architecture -> audit architecture -> trust architecture

memory -> skills -> methodology -> impressions
```

## Principle

Keep the main path clean:

```text
user input -> scene/intent -> relevant context -> agent loop -> tools/action -> output
```

Cognition should influence attention and association like intuition. It should not become a pending queue, admission gate, hard confirmation layer, fixed meta-command, or approval ceremony.

## Review Order

1. Is information captured with source, time, and scope?
2. Is scheduling natural: short things stay short, large work becomes a task, learning material is learned directly, Dream stays sidecar?
3. Does the loop plan, execute, verify, report, and learn?
4. Does the output surface match the situation?
5. Does memory promote through L0-L5 without losing key evidence?
6. Does evolution validate lessons before making them durable?
7. Does audit detect regressions without adding friction?
8. Does trust give the agent enough agency to help the user proactively?

## Done Standard

When the user says "continue", "next", "learn this", or "use your judgment", the agent should recover context, choose the right output surface, act, verify, remember what it did, and improve the next similar run.
