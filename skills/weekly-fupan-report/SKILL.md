# A 股周复盘报告生成 (Weekly Fupan Report)

## 一句话版本
基于复盘盒子数据，自动生成包含因果链条、执念阶段判断和明确操作建议的飞书周报。

## 核心逻辑：从数据到洞察
1. **数据层**：复盘盒子 DB (`~/.hermes/data/fupanhezi/fupanhezi.db`)
2. **分析层**：
   - **主线识别**：统计 `ztReson` 出现频次，找出资金共识最强的方向。
   - **执念阶段判断**：基于最高连板数 (`ztlbNum`) 和平均涨停家数，自动判定市场处于“情绪修复 / 执念形成 / 住相高潮 / 住相破裂”。
   - **因果链条**：将数据变化翻译为市场语言（如：主线高度集中 → 资金强共识 → 警惕分歧）。
3. **输出层**：飞书文档（`lark-cli docs +create`），使用 Callout 引用框和专业表格排版。

## 关键脚本路径
- `/root/hermes-agent/scripts/weekly_fupan.py`

## 执行流程
1. **获取交易日**：从 SQLite 读取最近 5 个交易日。
2. **每日汇总**：提取涨停家数、最高连板、核心方向（Top Reson）。
3. **全周分析**：
   - 计算全周最强主线及其持续性。
   - 判定当前执念阶段（Phase）。
4. **生成 Markdown**：
   - 使用 `<callout>` 标签突出核心特征和策略。
   - 使用 `<lark-table>` 展示每日数据对比。
5. **推送飞书**：调用 `lark-cli` 创建文档并推送到用户空间。

## 自动化部署
- **Cron**: 每周五 16:00 运行。
- **命令**: `crontab -e` 添加 `0 16 * * 5 cd /root/hermes-agent && python3 scripts/weekly_fupan.py`

## 避坑指南
- **字段映射**：复盘盒子的连板数是 `ztlbNum`，涨停原因是 `ztReson`（用 `+` 分隔）。不要使用旧字段名。
- **消息去重**：新闻面数据在不同日期可能重复，需在 Python 层做 `set` 去重。
- **飞书排版**：Markdown 中的换行在飞书中可能被忽略，建议使用 HTML 标签（如 `<lark-tr>`）或确保段落间有空行。
- **空数据处理**：如果数据库为空（如周末前未采集），脚本应报错退出而不是生成空白报告。

## 验证标准
- 飞书文档是否包含彩色 Callout 框？
- 是否有明确的“执念阶段”判断结论？
- 操作建议是否具体（进攻/防守/观察）而非空话？
