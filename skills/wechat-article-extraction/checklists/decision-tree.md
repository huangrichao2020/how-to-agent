# 微信文章提取决策树

## 1. 判断链接类型
- [ ] 是微信文章链接吗 (mp.weixin.qq.com)？→ 否：退出
- [ ] 短链接？→ 先解析重定向

## 2. 选择提取策略
- [ ] 浏览器可用？→ 不，会触发验证码
- [ ] 用 requests + HTML 解析？→ 是：继续

## 3. 判断解析结果
- [ ] 拿到完整正文？→ 是：完成
- [ ] 只有骨架？→ JS 动态渲染，需备用方案
- [ ] 被拦截？→ 检查 OG title 是否可用

## 4. 后处理
- [ ] HTML 实体已解码？→ 是
- [ ] 标签已清理？→ 是
- [ ] 元信息已提取？→ 是
