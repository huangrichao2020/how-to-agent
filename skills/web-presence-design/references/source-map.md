# Source Map

These sources are references for building the `web-presence-design` skill. Do
not copy them blindly; distill the useful pattern into the current project.

## Taste And Anti-Slop

- `Leonxlnx/taste-skill`: https://github.com/Leonxlnx/taste-skill
  - Use for taste control, anti-generic frontend rules, brand-kit thinking,
    image-led web art direction, and redesign heuristics.
  - Borrow the stance that frontend work needs aesthetic variables and
    anti-slop rules.
  - Do not import every hard ban as law; adapt to the current brand and project.

## Design Process

- `julianoczkowski/designer-skills`: https://github.com/julianoczkowski/designer-skills
  - Use for design brief, information architecture, frontend design, and design
    review workflow.
  - Borrow the sequence: brief -> IA -> tasks -> build -> screenshot critique.

## Landing Page Components

- `launch-ui/launch-ui`: https://github.com/launch-ui/launch-ui
  - Use for shadcn/Tailwind landing-page component ideas and production-ready
    section patterns.
- `nobruf/shadcn-landing-page`: https://github.com/nobruf/shadcn-landing-page
- `leoMirandaa/shadcn-landing-page`: https://github.com/leoMirandaa/shadcn-landing-page
  - Use as reference for common landing-page sections and implementation shape.
  - Do not clone visual identity wholesale.

## Course Pages

- `creativetimofficial/nextjs-tailwind-course-landing-page`:
  https://github.com/creativetimofficial/nextjs-tailwind-course-landing-page
  - Use for course page section coverage: hero, stats, features, testimonials,
    and conversion sections.
  - Add stronger learning outcome, curriculum, and proof modules when adapting.

## Customer Cases

- Shadcn case-study blocks:
  https://www.shadcnblocks.com/group/casestudies
- shadcn.io case studies and testimonials:
  https://www.shadcn.io/examples/navigation-menu-case-studies-and-testimonials
- Next.js case studies:
  https://nextjs.org/case-studies

Use these to model how customer proof is structured: customer context, result
metrics, industry tags, quotes, and links to deeper stories.
