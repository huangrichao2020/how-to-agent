# 财报前瞻分析框架

在公司发布季度财报前，使用此框架构建结构化前瞻分析。

## 工作流程

### Step 1: 收集背景信息

- 确认公司名称、报告季度、财报发布日期和时间（盘前 vs 盘后）
- 搜索一致预期数据（营收、EPS、关键分部指标）
- 回顾上一季度财报电话会议纪要中的指引和评论
- 收集近期分析师评级变动和目标价调整

### Step 2: 关键指标框架

构建针对该公司的 "值得关注" 指标体系：

**财务指标（通用）：**
- 营收 vs 一致预期（总量和分部）
- EPS vs 一致预期
- 利润率（毛利率、营业利润率、净利率）——扩张还是收缩？
- 自由现金流
- 前瞻指引 vs 一致预期

**运营指标（行业特定）：**
| 行业 | 关键运营指标 |
|------|-------------|
| 科技/SaaS | ARR、净留存率、RPO、客户数量 |
| 零售 | 同店销售、客流量、客单价 |
| 工业 | 积压订单、Book-to-Bill、价格 vs 销量 |
| 金融 | 净息差、信贷质量、贷款增长、手续费收入 |
| 医疗 | 处方量、患者量、管线更新 |

### Step 3: 情景分析

构建三种情景及股价影响：

| 情景 | 营收 | EPS | 关键驱动 | 股价反应 |
|------|------|-----|----------|----------|
| 牛市(Bull) | 超预期 | 超预期 |  |  |
| 基准(Base) | 符合预期 | 符合预期 |  |  |
| 熊市(Bear) | 不及预期 | 不及预期 |  |  |

对每种情景：
- 运营层面需要发生什么
- 管理层评论会释放什么信号
- 历史背景——类似业绩发布后股价如何反应？

### Step 4: 催化剂清单

确定决定股价反应的 3-5 个关键因素：

1. `[指标]` vs `[一致预期/私下预期]`——为什么重要
2. `[指引项]`——买方期望听到什么
3. `[叙事转变]`——是否有战略变化、并购、重组

### Step 5: 输出一页财报预览

包含：
- 公司、季度、财报日期
- 一致预期表
- 关键关注指标（按重要性排序）
- 牛/基/熊情景表
- 催化剂清单
- 交易设置：近期股价表现、期权隐含波动

## 错误处理与异常恢复

### 数据不可用
| 情况 | 处理方式 |
|------|----------|
| 一致预期数据缺失 | 使用分析师平均预测，或标注"数据不可用，基于历史增速估算" |
| 财报日期不确定 | 搜索多个来源确认，标注"日期可能变动" |
| 期权数据不可用 | 跳过隐含波动分析，用历史波动率替代 |
| 上一季度电话纪要找不到 | 使用更早季度的纪要，或标注"最新纪要不可用" |

### 分析质量保障
| 情况 | 处理方式 |
|------|----------|
| 一致预期频繁变动 | 标注预期数据的来源和更新日期，优先使用最新数据 |
| 公司无分析师覆盖 | 说明缺乏一致预期，基于行业平均和公司历史自建预期 |
| 财报期间特殊事件（疫情/并购/拆分） | 明确标注非常规因素，建议调整比较基准 |
| 多个分部数据不一致 | 标注数据矛盾，建议查阅原始财报文件 |

### 输出规范
- 所有预期数据必须标注**来源**和**日期**
- "私下预期"(whisper numbers) 需注明来自买方调查而非官方渠道
- 历史财报反应数据可搜索 `"[公司名] earnings reaction history"` 获取
- 期权隐含波动反映市场期望——与你的情景做对比验证

## 注意事项
- 一致预期会持续变化——始终记录数据来源和获取日期
- 买方私下预期往往比公开一致预期更能反映真实预期
- 历史财报反应有助于校准预期
- 本框架仅用于分析参考，不构成投资建议
