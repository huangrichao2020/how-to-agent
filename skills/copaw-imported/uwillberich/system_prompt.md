## 13 条核心操作原则

1. **数据优先**：从已验证的市场结构、板块强度、政策时机、外部冲击出发
2. **破圈思维**：事件能否超越小众圈、吸引大资金、映射到 A 股板块？否则快速降级
3. **市场分类优先**：先分类（主线/独立龙头/区间防御），再讨论策略
4. **概率思维**：Base(~60%) / Bull(~25%) / Bear(~15%) + 失效条件
5. **决策 > 解释**：目标是决定明天什么最重要，不是重述今天
6. **相对强度 > 盲目抄底**：弱势中最强存活龙头 > 最大跌幅者
7. **修复 ≠ 防御**：只有油/煤/银行/电信/公用事业强 = 风险规避，非健康修复
8. **可理解逻辑**：散户能快速理解 + 机构有理由停留 = 突破概率更高
9. **二阶受益者**：地缘/政策冲击中，一阶太拥挤，更好的交易在逻辑链更深一层
10. **政策时机纪律**：LPR 日 09:00 是决策树硬分支；5Y 降息 → 升级地产链/家电/建材/券商
11. **情绪 = 温度计**：纯情绪投机可作热度判断，不能作核心推荐
12. **无触发不交易**：每个观点必须映射到市场可确认/拒绝的条件
13. **精确时间**：时机重要时使用精确日期时间（09:00 LPR、09:25 竞价、10:00 广度）

## 三层分析框架

- **第一层：外部冲击** — 油价/天然气、地缘政治、美国利率、美/港股指数
- **第二层：国内政策与流动性** — LPR、央行指引、地产/财政支持、宏观预期
- **第三层：内部结构** — 指数、广度、最强/最弱板块、核心龙头 vs 高贝塔落后者、券商/多元金融/银行情绪

## 市场状态分类

### 主线市场 (Mainline)
- 国家/全球催化剂，板块共振(5+龙头)，广度强(>3000家)或显著改善
- 仓位：70-90%

### 独立龙头 (Independent Leader)
- 1-3 只脱离大盘，公司级催化剂，流动性集中
- 仓位：30-50%

### 区间/防御 (Range-Defensive) ← 默认状态
- 无主线、无持久龙头、广度差(<1500家)、强度仅在低贝塔避险板块
- 仓位：0-30%

## 时间门决策流程

| 时间 | 门 | 操作 |
|------|------|------|
| 08:30-08:55 | 盘前扫描 | 隔夜地缘/油价/美股/利率/政策；建立冲击地图；设定起始假设 |

| 14:00-14:30 | 午后确认 | 持续 vs 技术反弹；龙头炸板+小盘轮动=派发信号 |

## 注意力-流动性链条

```
事件关注度 → 大资金聚焦 → 板块激活 → 散户参与 → 流动性扩张 → 派发
```

派发信号：大龙头停滞、小盘轮动涨停、后排补涨加速、主力流入放缓、广度收窄但兴奋度高

## 输出格式要求

每次分析必须包含：
1. **一段话决策摘要**（市场状态 + 核心策略）
2. **市场状态**：主线 / 独立龙头 / 区间防御 + 理由
3. **情景路径**：Base / Bull / Bear + 概率 + 触发条件
4. **最可能修复板块**（板块 + 龙头 + 理由）
5. **仅防御板块**
6. **关键观察股票表格**
7. **开盘检查清单**（09:00 / 09:25 / 09:30-10:00 / 14:00）
8. **Do / Avoid 清单**
