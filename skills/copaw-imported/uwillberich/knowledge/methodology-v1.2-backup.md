## 一、核心方法论

### 基本逻辑链

```
事件破圈 → 大资金关注 → 板块启动 → 散户涌入 → 流动性充裕 → 拉高出货
```

所有分析都必须服务于这条链条。
**判断的核心问题永远是：「这个事件有没有破圈的可能？」**

---

## 二、主线行情判断标准

触发以下任意一条 = 主线信号：
- 国家级会议/文件点名的发展方向
- 多部委联合发文（两个部委以上）
- 全国性重大事件（政策突变/重大冲突/社会焦点）
- 全球性重大事件（影响世界的冲突/灾难/技术革命）

**主线确认标准**：板块内同时出现 10个以上个股涨停或集中大买单

---

## 三、独立龙行情判断标准

- 只有1~3只票脱离板块单独拉升，板块其他票无明显联动
- 无明显政策催化，量能持续放大
- 触发来源：重组/资产注入/业绩超预期/季节周期/大宗涨降价

---

## 四、震荡市判断标准

- 无主线、无独立龙
- 涨停家数低于40家
- 板块资金分散，无明显方向

## 五、三种持仓类型

### SHORT 短线（次日抢跑）

满足以下特征才归为 SHORT：
- ✓ K线直线拉升，角度陡峭（>70度）
- ✓ 单日成交量异常放大（明显非自然买盘，量化资金行为）

**操作**：次日开盘高位减仓离场，不恋战，不过夜

### MID 中线（趋势跟随）

满足以下特征才归为 MID：
- ✓ 不涨停但连续上涨，趋势良好
- ✓ 量能温和放大，无单日异常峰值

**操作**：跟随主力高抛低吸，震荡吸筹
**止损**：跌破15分钟图MA20线触发

### LONG 长线（价值低估）

满足以下特征才归为 LONG：
- ✓ 基本面优质，经常分红
- ✓ 股价低于MA120日线的90%时开始建仓
- ✓ 越低越买

**目标**：股价上涨至MA120日线×120%时卖出

## 七、独立行情六大触发模板

### 模板A：重组注入热门资产
- **特征**：ST股/小市值 + 跨界AI/芯片/算力
- **持仓**：SHORT，公告当日进，3~5个板离场
- ⚠️ 不在股票池范围内，仅用于识别市场情绪高度

### 模板B：硬科技产业链景气共振
- **特征**：有真实订单/业绩 + 对应英伟达/华为/特斯拉/SpaceX链
- **持仓**：MID，跟随产业链景气度，止损用MA20
- ✅ 股票池主要覆盖此类

### 模板C：玄学/名字炒作
- **特征**：名字含生肖/寓意 + 低市值 + 无基本面
- **持仓**：不参与，仅作为市场情绪温度计
- **规律**：生肖年前1个月开始炒作，连板超10个换手骤降则见顶

### 模板D：大宗商品涨价
- **特征**：产品价格暴涨 + A股上游对应标的
- **持仓**：SHORT到MID，视涨价持续性决定
- **触发**：上海钢联报价异常拉升时立刻触发扫描

### 模板E：地缘/政策强事件
- **特征**：国家级事件 + 地域/行业直接受益
- **持仓**：MID，事件发酵期跟随高抛低吸

### 模板F：次新股无套牢盘
- **特征**：上市3~6个月内 + 市值低于30亿 + 题材契合
- **持仓**：不参与，风险超出仓位管理范围

## 九、强日期锚定事件规则

### 判断标准
- ✓ 有明确的、公开的、不可更改的日期
- ✓ 稀缺性高（十年一次 > 每年一次 > 随机事件）
- ✓ 全国/全球关注度

### 常见类型
阅兵 / 重大纪念日 / 奥运会 / 世博会 / 重大外交峰会

### 操作逻辑
- 事件公布后 → 立刻识别受益板块 → 中线埋伏辨识度最高的龙头
- 越接近日期情绪越强 → 日期当天或前一天考虑减仓

## 十、地缘事件受益资产识别框架

地缘事件发生后，**不要买最直觉的板块，要找第二层逻辑**：

| 层级 | 案例 | 特点 |
|------|------|------|
| 第一层（直觉层） | 台海冲突→军工 / 俄乌冲突→能源军工 | 竞争者最多，溢价最低 |
| 第二层（逻辑层） | 台海统一预期→福建/平潭 / 俄乌停火→重建材料 | 竞争者少，溢价更高 |

### 判断标准
- ✓ 辨识度高（名字/地理/政策直接相关）
- ✓ 散户能看懂逻辑（破圈条件）
- ✓ 大资金有理由长期持有（不是一日游）

---

## 十一、事件类型与持仓策略对应

### 有结束日期的事件（阅兵/奥运/大会）
- **策略** = 提前埋伏 + 日期前减仓
- **退出信号** = 日期临近，情绪见顶

### 无结束日期的事件（地缘冲突/政策持续）
- **策略** = 事件确认后跟进 + 情绪高抛低吸
- **退出信号** = 官方态度软化 / 板块量能萎缩 / 换手率骤降

---

## 十二、妖股退出硬规则

- 连板超过10个且换手骤降 → 次日开盘强制减仓
- 监管介入停牌核查 → 复牌日高开减仓
- 同板块出现更强新龙头 → 切换，不恋旧标的

### 妖股寿命参考
- 重组类/玄学类 → 3周内
- 科技产业链/地缘事件 → 1~2个月
- 周期涨价/真实业绩 → 2个月以上

### 历史妖过的股票池内标的
胜宏科技 / 新易盛 / 工业富联 / 张江高科 / 润和软件
（再次启动需确认新催化剂）

---

## 十三、仓位与止盈止损规则

- 建仓：2万
- 加减仓：每次1万（买卖均控制在1万）
- 止盈：+15%

### 止损规则
- 跌破15分钟图MA20线 → 先减半仓
- 继续跌 → 继续减
- 上穿MA20线 → 重新加回

## 十六、信息收集执行顺序

### 盘前执行顺序

**Step 1 — 宏观事件层**
- "今日国务院发改委工信部最新政策"
- "多部委联合发文产业政策"
- "今日A股宏观面解读"
- "昨夜美股纳指英伟达特斯拉苹果涨跌"
- "大宗商品铜铝原油今日"
- **输出**：是否触发主线信号？YES/NO

**Step 2 — 板块共振层**

> ⚡ 第一优先级：先查金融三组（见第十七节），30秒完成市场定性初判
> 再用以下数据做最终确认：

- "今日A股涨停家数"
- "今日沪深两市主力资金净流入"
- "今日北向资金净流入"
- "今日主力资金净流入前十板块"
- "今日连板股数量及晋级率"
- "上证指数今日行情"
- "中证500今日行情"
- "美元兑人民币最新汇率"
- 配合资讯搜索："今日A股主线题材板块轮动" / "今日龙虎榜游资营业部"
- **输出**：市场定性（主线/独立龙/震荡）三选一

**Step 3 — 个股执行层**

根据Step2定性，只查当日相关链条（不全链扫）：

| 主线类型 | 查询链条 |
|----------|----------|
| AI/信创 | AI信创 + 英伟达链 |
| 军工 | 军工链 + SpaceX链 |
| 消费电子 | 苹果链 + PCB链 |
| 光通信 | 光通信链 + 英伟达链 |
| 震荡行情 | 只查持仓票所在链条 |

每条链只查2只龙头，单股查询格式：
- 资讯搜索: "{股票名}最新资讯"
- 数据查询: "{股票名}今日最新价涨跌幅"
- 数据查询: "{股票名}今日主力净流入"
- 数据查询: "{股票名}今日换手率成交量"

**Step 4 — 止损预警**

对每只持仓票获取15分钟K线 → 计算MA20 → 判断状态

- 资讯搜索: "今日A股尾盘涨停封板情况"

## 十七、大盘情绪定性辅助（金融三级表）

> **使用时机**：每日 Step 2 的第一步，优先于涨停数据，30秒完成初判。

金融板块的表现是大盘情绪最直接的晴雨表，判断逻辑如下：

| 金融板块信号 | 大盘定性 | 对应策略 |
|---|---|---|
| 证券板块走强 | 大进攻行情 | 重仓进攻板块，追主线龙 |
| 多元金融走强（不含证券/银行） | 小突破行情 | 轻仓跟进，做独立龙或板块轮动 |
| 银行走强（证券/多元不强） | 纯防御行情 | 空仓观望，只做防御组 |
| 三组同时走强 | 流动性泛滥（牛市特征） | 满仓进攻，仓位可适当放宽 |

### 逻辑解释

- **证券走强**：券商吃交易佣金，涨代表聪明钱预期成交量放大，今日/本周有大行情
- **多元金融走强**：信托/租赁/期货吃市场波动，走强说明局部布局，非全面进攻
- **银行走强**：大资金抱团低波红利，代表"避险"不是进攻，追涨其他板块风险极高

### 与现有市场定性的联动

```
证券走强 → 直接对应"主线行情"策略
多元金融走强 → 直接对应"独立龙行情"策略
银行走强 → 直接对应"震荡观望"策略
```

金融三级表的信号和涨停家数两相印证，一致则定性可信；若矛盾，以金融三级表为准。

## 十八、箱体理论买卖点执行规则

### 箱体的定义

股价在某个价格区间内反复震荡，上沿（阻力位）和下沿（支撑位）构成箱体。
**有效箱体**：至少经历2次以上的上下震荡验证，单边趋势不构成箱体。

### 模式一：箱体内做T（震荡行情首选）

**适用场景**：市场震荡期，无主线，个股横盘整理

```
买点：箱体下沿附近（支撑位）建仓 1万
卖点：箱体上沿附近（压力位）减仓
止损：跌破箱体下沿超过3% → 视为支撑破位，立即清仓
```

反复操作，每次1万，高抛低吸降低持仓成本。

### 模式二：放量突破后缩量回踩（趋势启动买点）

**触发条件**：
- ✓ 收盘价有效站上箱体上沿
- ✓ 突破当日成交量 ≥ 近5日均量的1.5倍

**操作逻辑**：
```
突破当日 → 不追高
等待回调 → 缩量回踩原箱体上沿（上沿变支撑）
回踩建仓 → 2万建仓
止损 → 跌破回踩支撑（原箱体上沿）清仓
```

**本质**：放量突破是方向确认，缩量回踩是成本优化，两者缺一不可。

### 结合行情的判断

| 行情类型 | 突破后操作 | 原因 |
|----------|-----------|------|
| 主线行情 | 可适当追突破当日 | 主线资金不给等待机会 |
| 震荡行情 | 必须等缩量回踩 | 假突破概率极高 |
| 无主线行情 | 谨慎参与 | 优先确认是否有独立催化剂 |

## 十九、板块龙头出货识别规则

### 现象描述

板块内几百亿市值的大票（机构重仓）出现**高位横盘、量能萎缩、不再新高**时，同板块小盘股（市值20~50亿）会开始被资金轮番拉涨停。

**本质**：小盘股拉升制造"板块还在涨"的假象，为大票机构提供出货时间窗口。

### 三信号识别

```
信号一：大票高位横盘3天以上 + 成交量持续萎缩
信号二：同板块小盘股开始轮番涨停（每天换一只）
信号三：小票涨停，龙头大票不跟甚至微跌
```

三信号同时出现 = 板块出货阶段，进入风险模式。

### 对应操作

| 情况 | 操作 |
|------|------|
| 持有大票 | 开始分批减仓，每次1万 |
| 大票横盘期间 | 可用箱体模式一做T，不加仓 |
| 小盘涨停诱惑 | 严禁追涨，就是接盘陷阱 |
| 等待下一轮 | 板块调整完毕后重新评估启动信号 |

### 与市场定性的联动

| 原定性 | 出现出货信号后 | 调整后定性 |
|--------|--------------|-----------|
| 主线板块 | 降级 | 主线尾声，减少关注 |
| 独立龙板块 | 降级 | 出货行情，清仓 |

## 二十、盘后复盘报告生成规则（战役叙事格式）

### 叙事风格要求

- 用"资金战役"的军事视角描述市场
- 每个判断必须有数据支撑，不捏造
- 有画面感，不废话
- 结尾必须给出明日具体操作方向

### 个股角色分类规则

拿到当日涨停/强势股数据后，按以下规则分配角色：

| 角色 | 分配条件 | 描述重点 |
|------|---------|---------|
| 最高指挥部（高标阵营） | 当日连板数最高的1~2只票 | 板数/封板质量/换手/空中楼阁风险 |
| 主攻部队（主线龙头） | 主线板块内连板晋级成功、换手充分的票 | 题材逻辑/资金认可度/持续性 |
| 特种部队（独立逻辑） | 脱离主线、有独立催化剂、成交量异常放大 | 独立逻辑来源/主力性质（机构/顶级游资） |
| 游击队（尾盘伏击） | 午后或尾盘突然发动、有政策赌博属性 | 赌的是什么消息/短线套利还是持续逻辑 |

## 二十一、人性、执念与住相：从金融角度理解供需与主线演化

### 核心结论

股价不是事实本身，股价是**人群对事实的关系**。  
买卖股票，不是在交易“真相”，而是在交易：
- 谁开始相信
- 谁开始怀疑
- 谁必须买
- 谁急着卖

所以交易中的“供需”，不能只理解成产品供需，更要理解成：
- 注意力供需
- 叙事供需
- 资金供需
- 筹码供需

### 1. 空性：股票和板块没有固定意义

同一条消息、同一个板块、同一只股票，在不同阶段、不同资金眼里，意义完全不同。

例如：
- 油价上涨，对上游资源股是利多，对制造业是利空，对指数是风险偏好打击
- AI 发布会，对前排核心是催化，对后排跟风是出货窗口
- 低估值，对长期资金是安全垫，对短线资金可能毫无吸引力

**交易翻译**：
- 不要问“这票到底好不好”
- 要问“这票在当前关系里，对谁有意义”

### 2. 妙用：同一事件，对不同人有不同用途

同一个事件，对不同参与者的“用”完全不同：
- 机构：看持续性、容量、业绩映射、估值切换
- 游资：看辨识度、情绪扩散、封板强度、接力意愿
- 散户：看热度、故事、涨停示范、能否翻本
- 被套盘：看能不能解套
- 踏空者：看会不会再不给机会

**交易翻译**：
- 不是问“消息利好不利好”
- 是问“谁会拿这条消息去干什么”

### 3. 住相：一切泡沫和踩踏的心理底层

住相，就是把阶段性的有效，当成永恒真理。

市场里最常见的住相：
- “龙头不会死”
- “跌这么多不可能再跌”
- “低估一定会修复”
- “政策提了就一定兑现”
- “这次和以前不一样”
- “我套了这么多，反弹肯定会回本”

一旦住相形成，市场参与者就会进入：

`排异 -> 只找支持证据 -> 情绪化 -> 偏见 -> 更深的执念`

这就是泡沫顶部、抱团尾声、以及破位后死扛的心理结构。

### 4. 执念：主线真正的燃料

没有执念，就没有持续主线。

主线之所以能走出来，不只是因为逻辑对，而是因为它承载了群体执念。常见执念包括：
- 对技术革命的执念
- 对资源稀缺的执念
- 对政策红利的执念
- 对国产替代的执念
- 对翻本的执念
- 对“错过这次就没机会”的执念

**判断主线，不只看消息，还要看它承载了哪种执念。**

### 5. 随机与必然：可交易的不是事件，是人群反应

事件常常是随机的，但反应不是。

可交易的核心不是“发生了什么”，而是：
- 这群人之前住了什么相
- 这条消息会强化还是打碎这个住相
- 谁会因此被迫买入
- 谁会因此被迫卖出

**交易翻译**：
- 真正可预判的，不是新闻本身
- 而是既有执念下的人群必然反应

### 6. 金融里的供需重定义

#### 需求端

需求不只是“想买”，而是以下因素的叠加：
- 注意力：大家先看见，才会讨论
- 叙事认同：觉得这件事“有未来”
- 踏空焦虑：怕错过
- 职业压力：基金经理、游资、交易员不能落后
- 翻本冲动：亏损者急于扭转命运

#### 供给端

供给不只是“有人卖”，而是以下筹码来源的叠加：
- 获利盘兑现
- 解套盘抛压
- 后排补涨制造的新供给
- 大资金借流动性出货
- 杠杆盘和情绪盘的被动止损

**交易判断**：
- 当需求增速快于优质筹码供给，主线加速
- 当全民都在讲同一个故事，后排大量涌现，供给开始泛滥，往往接近派发

### 7. 主线的人性演化六阶段

#### 阶段一：少数先知期
- 只有小部分人看懂
- 叙事刚起，筹码便宜
- 最难买，也最值得买

#### 阶段二：机构试错期
- 中军开始放量
- 研报、公告、订单、政策映射出现
- 大资金开始试探

#### 阶段三：游资点火期
- 龙头打出辨识度
- 板块开始扩散
- 市场开始形成可见赚钱效应

#### 阶段四：散户共识期
- 讨论度激增
- 后排跟风开始泛滥
- 主线最顺，赚钱最容易，但成本也在变高

#### 阶段五：全民住相期
- “这就是未来”“永远不会结束”成为主流表达
- 大家把阶段性有效当成永恒真理
- 这是最危险的阶段

#### 阶段六：龙头滞涨 / 后排乱舞 / 派发期
- 龙头横盘，不再新高
- 后排轮流涨停
- 故事比业绩更热闹
- 供给开始大于新增需求

这时就不是主升，而是在借人性出货。

### 8. 真正赚钱的“少数人”怎么站位

不是永远和大众反着来，而是：

- 前期做少数：执念刚形成时先上车
- 中期借多数：共识成形时跟着主升吃最厚一段
- 后期再做少数：当大众开始住相时先下车

**铁律**：
- 早期，跟多数作对
- 中期，借多数抬轿
- 后期，在多数最确信时离场

### 9. 交易里的五个必问问题

每次要做一个方向，先问：

1. 这个方向现在承载的是哪种群体执念？
2. 当前主导这条线的是机构、游资，还是散户？
3. 现在是执念强化阶段，还是住相破裂阶段？
4. 当前新增的是需求，还是新增的是供给？
5. 这单是在买“少数人刚看懂”，还是买“多数人已经上头”？

### 10. 买入与卖出的新标准

#### 买入标准
- 买的是“人群刚开始形成共识”，不是“人群已经喊到震天响”
- 买的是“需求正在扩张”，不是“故事已经人尽皆知”
- 买的是“龙头或中军仍在强化”，不是“后排开始乱舞”

#### 卖出标准
- 卖的不是某条消息变坏了，而是：
  - 群体住相开始固化
  - 龙头不再领涨
  - 后排疯狂补涨
  - 供给突然变多
  - 大家开始用绝对化语言描述趋势

**一句话**：
- 买的是执念形成
- 卖的是住相破裂前夜

### 11. 方法论升级后的总公式

以后所有交易判断，统一改成这条总公式：

`事件 -> 执念 -> 住相 -> 资金行为 -> 板块扩散 -> 筹码交换 -> 住相破裂`

原来的“事件驱动 + 板块联动 + 龙头确认”继续保留；  
这一节新增的是：**用人性解释为什么它会持续，以及为什么它会结束。**

### 12. 最终铁律

`买的不是事实，买的是人群对事实的执念；卖的不是利空，卖的是住相开始破裂。`
