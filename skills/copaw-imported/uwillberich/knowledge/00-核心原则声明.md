## 🔧 工具定位：45 个同花顺技能

**技能是数据采集工具，服务于 uwillberich 核心**

### 技能的职责

```
✓ 数据采集：行情、财务、公告、新闻、宏观数据...
✓ 初步筛选：问财选股、板块排序、条件过滤...
✓ 信息呈现：公司画像、产业链解读、竞争格局...
```

### 技能不能做什么

```
✗ 不能替代市场分类 (主线/独立龙头/区间防御)
✗ 不能替代概率判断 (Base/Bull/Bear)
✗ 不能替代时间门纪律 (什么时间做什么决策)
✗ 不能直接输出交易决策 (买/卖/观望/仓位)
```

## 🎯 正确使用方式

### ❌ 错误示例

```
用户：今天买什么？

错误回答：
→ 问财选板块显示 CPO 涨幅第一，买 CPO
→ 新闻搜索显示利好新能源，买新能源
→ 机构研究与评级查询显示茅台目标价 2000，买茅台

问题：
- 没有市场分类
- 没有概率情景
- 没有时间门判断
- 用技能输出替代决策
```

### ✅ 正确示例

```
用户：今天买什么？

正确回答：

【08:30 隔夜扫描】
外部冲击层评估：
- 隔夜美股：纳指 +1.2% → 正面
- 地缘政治：中东稳定 → 中性
- 油价：Brent $85 (+2%) → 轻微负面
→ 综合评分：中性偏正面

【09:00 政策门】
国内政策层评估：
- LPR: 5Y 持平 4.2% → 中性
- 央行：净投放 500 亿 → 轻微宽松
→ 综合评分：中性

【09:30 开盘确认】
内部市场结构层评估：
- 问财选板块：CPO +5%，主力 +35 亿
- 行情数据查询：涨停 18 家，涨跌比 2800/1700
- 问财选 A 股：上涨占比 68%
→ 市场分类：主线市场 (成长修复)

【决策输出】
Base (60%): CPO 延续修复，仓位 75%
Bull (25%): 放量突破，加仓至 85%
Bear (15%): 跌破支撑，减仓至 50%

【观察股票池】
- 中际旭创 (300308): CPO 龙头
- 新易盛 (300502): CPO 弹性
- 阳光电源 (300274): 光伏跟随

【时间门纪律】
- 10:00 检查广度是否维持
- 14:00 确认持续性
```

## 📋 决策流程铁律

```
1. 先分类，后决策
   → 市场状态是什么？(主线/独立龙头/区间防御)

2. 先概率，后仓位
   → Base/Bull/Bear 情景和概率？

3. 先时间，后行动
   → 当前是什么时间门？该做什么决策？

4. 先数据，后判断
   → 用技能采集数据，用 uwillberich 做判断

5. 先核心，后工具
   → uwillberich 方法论优先，技能服务于核心
```

---

## 🔒 不可触碰的红线

以下行为严格禁止：

1. **用技能输出直接作为决策**
   - "问财选板块显示 XX 最强，所以买 XX"

2. **跳过时间门决策**
   - 08:30 不做隔夜扫描就直接决策
   - 10:00 不做广度检查就追涨

3. **忽略市场分类**
   - 在区间防御市场使用主线市场策略

4. **无视概率情景**
   - 只说"会涨"，不说 Base/Bull/Bear 概率

5. **脱离股票池管理**
   - 交易不在 13 太保/跨周期锚定 12 的票
