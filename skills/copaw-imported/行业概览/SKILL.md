# 行业概览 (Sector Overview)

生成覆盖市场动态、竞争格局、核心参与者和主题趋势的行业全景报告。

## Trigger

- 用户要求生成某行业的概览/全景报告
- 关键词：行业分析、赛道概览、板块梳理、landscape、sector overview
- 不适用于：个股深度研究、宏观策略报告（需调用其他 skill）

## Workflow

### Step 1: Define Scope

在开始前与用户确认（若已明确则跳过）：

| 维度 | 说明 |
|------|------|
| **Sector / subsector** | 什么行业？定义范围（如"新能源汽车"而非泛泛"汽车行业"） |
| **Purpose** | 客户报告 / 内部研究 / 路演讲义 / 创意生成 |
| **Depth** | 概览级（5-10页）或 深度级（20-30页） |
| **Angle** | 中性全景 vs. 主题性论点（如"AI 基础设施投资浪潮"） |
| **Universe** | 仅上市公司，还是包含非上市企业？ |
| **Region** | 全球视角 / 中国为主 / 特定市场 |

### Step 2: Market Overview

**Market Size & Growth**
- 总可寻址市场 (TAM)，注明数据来源
- 历史增长率（5年 CAGR）
- 预测增长率及关键假设
- 市场细分（按产品、地域、终端市场、客户类型）

**Industry Structure**
- 分散 vs. 集中 — 前 5 大市场份额
- 价值链地图 — 价值在哪个环节沉淀？
- 商业模式类型（订阅、交易、授权、服务）
- 进入壁垒（资本、监管、技术、网络效应）

**Key Trends & Drivers**
- 长期顺风因素（3-5个主要趋势）
- 逆风因素与风险
- 技术颠覆向量
- 监管动态
- M&A 活动与整合趋势

### Step 3: Competitive Landscape

**Company Profiles**（头部 5-10 家公司）：

| Company | Revenue | Growth | EBITDA Margin | Market Share | Key Differentiator |
|---------|---------|--------|--------------|-------------|-------------------|
| | | | | | |

每家公司的简要画像：
- 业务描述（2-3句话）
- 战略定位与护城河
- 近期动态（财报、M&A、产品发布）
- 估值快照（P/E、EV/EBITDA、EV/Revenue）

**Competitive Dynamics**
- 竞争维度（价格、产品、服务、渠道）
- 谁在抢占/丢失份额及原因
- 新进入者或跨界玩家的颠覆风险

### Step 4: Valuation Context

- 板块交易乘数（当前值与历史区间）
- 溢价/折价的驱动因素（增长率、利润率、市场地位）
- 近期 M&A 交易乘数
- 板块与大盘的相对估值

### Step 5: Investment Implications

- 最佳风险/收益机会在哪里？
- 可通过该板块表达的主题性押注
- 板块核心分歧（多方 vs. 空方论点）
- 可能改变板块叙事的关键催化剂

### Step 6: Output

- Word 文档或 PowerPoint，包含：
  - 市场概览与规模
  - 竞争格局地图
  - 公司对比表
  - 估值摘要
  - 关键图表：市场增长、份额趋势、估值历史
- Excel 附录（详细公司数据）

## 异常处理 (Exception Handling)

### 数据获取失败 / 超时

| 场景 | 异常类型 | fallback 策略 |
|------|---------|-------------|
| 数据源 API 超时或连接失败 | 网络超时 (timeout) | 切换备用数据源；若全部失败，使用最近一次缓存数据并标注"非实时" |
| 市场规模数据缺失 | 数据不可用 | 使用相邻行业数据推算；标注"估算"并说明方法论 |
| 数据源冲突（不同来源 TAM 差异大） | 数据矛盾/错误 | 列出区间范围，取中位数并注明数据源分歧原因 |
| 某公司近期数据未披露 | 信息缺失 | 使用最近一期可用数据 + 明确标注数据截止日期 |
| 非上市公司无财务数据 | 数据不可得 | 使用融资历程、招聘规模、专利数等替代指标兜底 |

### 范围与质量兜底

| 场景 | 应对策略 |
|------|---------|
| 行业定义过于宽泛 | 建议细分子赛道；如"科技行业"→"AI 芯片"或"SaaS" |
| 行业定义过于狭窄 | 确认用户意图；如确实小众，标注"利基市场"并对比相邻大市场 |
| 跨行业融合（如"车路云一体化"） | 拆解为多个子行业分别分析后整合 |
| 数据过于陈旧（>2年） | 标注"历史数据"；补充最新可得的定性趋势 |
| 缺乏权威来源 | 优先使用：Bloomberg、Wind、Gartner、IDC、Frost & Sullivan、行业协会报告 |
| 主观判断过多（质量风险） | 区分事实与观点；用"据XX报告"替代"我们认为" |
| 生成失败或输出不完整 | 检查 Prompt 是否过长导致截断；分段生成后合并 |

## Important Notes

- 所有市场规模数据必须注明来源 — 引用研究机构或方法论
- 区分 TAM 炒作与可实际触达的市场
- 行业概览老化快 — 标注日期并标记可能过时的数据
- 图表必不可少 — 市场规模瀑布图、竞争定位矩阵、估值散点图
- 面向客户时，将"所以怎样"与其具体情境结合（M&A 标的识别、竞争定位、市场进入）
- **中文输出时**：保持专业术语的中英双语标注（首次出现时），如"总可寻址市场 (TAM)"
