# A股盘后报告

从数据到决策的完整流程。来源：[feishuclaw](https://github.com/huangrichao2020/feishuclaw)

## 触发条件

用户要求：
- "做盘后报告"
- "今天复盘"
- "明日计划"
- "收盘后分析"

## 核心原则

盘后报告不是"总结今天发生了什么"，而是**"把今天的盘面翻译成明天可执行的交易计划"**。

**不是选项题，是指令题。**
**不是安慰，是纪律。**

## 制作流程（8步决策漏斗）

### Step 1：收集原始数据（盘后 15:00 - 15:30）

**必须获取的数据项**：
- 上证指数涨跌
- 涨停/跌停家数
- 上涨/下跌家数占比（广度验证）
- 北向资金流向
- 板块涨幅榜 Top5
- 涨停股列表
- 重大新闻/政策
- 美股前夜表现（纳指/英伟达/特斯拉）
- 大宗商品（铜铝原油）
- 汇率（USDCNY）

**工具优先级**：
1. i问财 Skills（结构化查询）
2. web_search（快速搜索）
3. browser（抓取财经页面）

### Step 2：市场状态判定

| 状态 | 判定标准 | 明日策略 |
|------|----------|----------|
| **主线行情** | 国家级催化 + 5+龙头共振 + 涨停≥40 + 上涨>3000家 | 追主线龙，重仓 |
| **独立龙行情** | 1-3只票脱离板块单独拉升 + 公司级催化 | 做特定龙头，轻仓 |
| **震荡防御** | 无主线 + 涨停<40 + 上涨<1500 + 银行/防御领涨 | 空仓/只减不加 |

**判定口诀**：看涨停 → 看上涨占比 → 看金融三级表 → 交叉验证
**冲突时以广度为准**（广度是真理）。

### Step 3：板块强度排序

强度公式：
```
强度 = 涨幅均值×0.3 + 主力净流入×0.3 + 涨停家数×0.2 + 上涨占比×0.2
```

1. 找 Top5 板块
2. 看内部涨停数量（>3 才算板块效应）
3. 看主力流向（涨+流入=健康；涨+流出=出货）

### Step 4：执念阶段定位

问："这个事件/板块，处在执念六阶段的哪一步？"

| 阶段 | 特征 | 动作 |
|------|------|------|
| 1. 少数先知 | 少数人讨论，股价刚动 | 最难买也最值得买 |
| 2. 机构试错 | 中军放量，研报出现 | 试探性建仓 |
| 3. 游资点火 | 龙头打出辨识度 | 跟随确认 |
| 4. 散户共识 | 到处讨论，后排泛滥 | 赚钱但成本高 |
| 5. 全民住相 | "这就是未来" | 最危险，准备离场 |
| 6. 派发 | 龙头横盘，小票轮动 | 分批减仓，不追 |

### Step 5：事件破圈评估

**核心问题**：这个事件有没有破圈的可能？

破圈特征：
- 国家级政策/文件
- 全球性事件（英伟达财报等）
- 产品级突破（有真实订单/业绩）
- 普通人能听懂的因果链

### Step 6：金融三级表快判

| 谁在动 | 定性 | 动作 |
|--------|------|------|
| 证券板块 | 大进攻 | 重仓追主线龙 |
| 多元金融 | 小突破 | 轻仓做独立龙 |
| 银行（证券不强） | 纯防御 | 空仓观望 |
| 三组同强 | 流动性泛滥 | 满仓进攻 |

**铁律：若与涨停家数矛盾，以金融三级表为准。**

### Step 7：持仓审视

逐只检查：
- 是否在当前主线？不是 → 倾向减仓
- 是否在执念前期/中期？后期 → 离场
- MA20 是否跌破？跌破 → 触发止损
- 主力流入还是流出？流出 → 危险
- 是否符合"允许做的3种跟随"？不符合 → 不做

### Step 8：输出报告

固定输出格式：

```
━━━ 市场定性 ━━━
【市场状态】主线/独立龙/震荡防御
【核心信号】涨停X家 / 上涨X家 / 北向X亿 / XX领涨
【定性】一句话总结

━━━ 宏观信号 ━━━
政策面：（有无主线级事件）
美股面：（纳指/英伟达/特斯拉涨跌）
大宗面：（铜铝原油方向 → A股影响）

━━━ 重点关注 ━━━
板块：XX
逻辑：XX（事件来源 + 破圈可能性）
代表票：XX
持仓类型：SHORT / MID / LONG

━━━ 持仓预警 ━━━
[股票名] 现价XX 成本XX 盈亏XX% MA20:XX 状态：✅安全 / ⚠️注意 / 🔴预警 / 🚨止损

━━━ 明日盘前提示 ━━━
【结论】可做/不做/等确认/只减不加
【09:20 竞价】看什么
【09:30 确认】确认什么
【10:00 验证】验证什么
【Do】...
【Avoid】...
```

## 决策者语态

- 先给结论，再给依据，再给动作
- 结尾用执行句：`按预案执行` / `先减这一只` / `这单不做`
