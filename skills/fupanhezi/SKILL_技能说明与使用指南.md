# 复盘盒子

## 一句话版本
A 股短线第一数据源，采集涨停梯队/题材轮动/消息面/游资席位数据。

## 触发条件
- ✅ **触发**：复盘盒子、涨停梯队、游资席位、题材轮动、连板股、龙头股、炸板、消息面
- ❌ **不触发**：MX API 数据、基本面分析、财务数据、通用股票查询

## 数据采集维度

| 维度 | 说明 | 更新频率 |
|------|------|----------|
| 涨停梯队 | 首板/2板/3板+ 梯队结构 | 盘中实时 |
| 题材轮动 | 热点题材及持续性 | 盘中实时 |
| 消息面 | 政策/公告/舆情 | 盘中实时 |
| 游资席位 | 龙虎榜席位及买卖金额 | 盘后 |
| 炸板统计 | 炸板率/回封情况 | 盘中实时 |
| 连板情绪 | 市场赚钱效应指标 | 盘中实时 |

## 工作流
1. **确认交易时间**：非交易日跳过盘中数据
2. **采集涨停梯队**：拉取当日涨停板个股及连板高度
3. **采集题材数据**：提取热点题材及关联个股
4. **采集游资数据**：拉取龙虎榜/席位数据（盘后）
5. **采集消息面**：整理影响板块的重要消息
6. **数据整合输出**：汇总为结构化复盘报告

## 数据输出格式

{

## 异常处理

### 数据源不可达
- **症状**：API 超时、返回空数据、连接被拒绝
- **排查**：
  1. 检查复盘盒子 API 服务状态
  2. 确认网络连接（防火墙/代理配置）
  3. 验证 API Key/Token 是否过期
- **恢复**：切换备用数据源（如东方财富接口）或等待服务恢复

### 盘中数据延迟
- **症状**：数据非实时、与行情软件不一致
- **排查**：复盘盒子推送频率、网络延迟、缓存未刷新
- **恢复**：手动触发刷新、清除本地缓存

### 非交易日误触发
- **症状**：查询到空数据或旧数据
- **排查**：确认是否为周末/节假日
- **恢复**：跳过采集，返回提示"今日非交易日"

### 数据格式异常
- **症状**：JSON 解析失败、字段缺失
- **排查**：API 响应格式变更、部分字段临时缺失
- **恢复**：增加容错逻辑，缺失字段标记为 null 而非中断

## 常见坑点
- ⚠️ 复盘盒子数据仅在交易时段更新，盘后数据（龙虎榜）通常在 17:30 后更新
- ⚠️ 涨停数据以交易所最终披露为准，盘中数据可能有变动
- ⚠️ 游资席位名称可能变更，需定期更新映射表
- ⚠️ 非交易日（含调休）需特殊处理，避免采集到陈旧数据

## 与其他数据源的关系
- 复盘盒子 ≠ MX API（不同数据源，勿混用）
- 复盘盒子侧重短线情绪，Baostock/AkShare 侧重历史行情
- 交叉验证时以交易所官方数据为准
