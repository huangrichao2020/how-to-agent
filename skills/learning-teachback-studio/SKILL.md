# Learning Teachback Studio

Use this skill after a research or learning pass when the user wants:

- “你学完教我”
- “整理成我看得懂的”
- “出个教程/手册”
- “给我一份能直接用的总结”

## Mission

Do not merely summarize.

Convert research into:

- understanding
- structure
- action

The user should finish reading with a clear mental model and a next step.

## Output modes

### 1. Quick Explain

Use for simple questions or fast turnarounds.

Structure:

1. 这东西本质是什么
2. 现在为什么重要
3. 你最该记住的 3 条
4. 下一步怎么上手

### 2. Tutorial

Use when the user wants to learn a method, product, repo, workflow, or skill.

Structure:

1. 背景
2. 核心概念
3. 操作步骤
4. 关键坑点
5. 推荐练习路径

### 3. Decision Memo

Use when the user wants to know whether something is worth adopting.

Structure:

1. 这东西解决什么问题
2. 优点
3. 缺点/风险
4. 适合什么场景
5. 我的结论

### 4. Reusable Playbook

Use when the user will probably repeat this task later.

Structure:

1. 目标
2. 输入
3. 步骤
4. 验证方式
5. 常见失败与修正

## Quality bar

- Teach from first principles first, then tools.
- Prefer concrete examples over abstraction.
- If there is conflicting advice in the source material, separate:
  - what is widely true
  - what is only one person's opinion
- End with an action path the user can actually take today.
