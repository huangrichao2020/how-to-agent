# A股多宇宙情景推演

> 基于 agentara/doctor-strange 改造，融合交易宪法（人性→执念→住相→供需）

**核心逻辑**：不做预测，做多路径推演。每个路径是一个独立宇宙，由因果链驱动，不是随机猜测。

---

## 交易宪法映射

```
人性(L5) → 执念(L4) → 住相(L3) → 供需(L2)
  ↓          ↓          ↓          ↓
市场为什么  资金共识    涨停板/连板  板块强度/资金流向
```

**推演原则**：
- 买的是执念形成，卖的是住相破裂前夜
- 只做跟随，不做主观抄底
- 只做前排和确认，不做后排和尾声
- 不猜底摸顶，试仓是付费买信息

---

## 模式定义

### Mode 1: SIMULATE（新推演）

**Step 1 — 提取场景**

从用户消息识别：
- **标的**：个股代码/名称 或 板块名称
- **当前状态**：价格、涨幅、连板数、所属板块
- **时间窗口**：推演 horizon（日内/1周/1月）
- **决策类型**：买入/持有/卖出/观望
- **仓位约束**：用户资金量、风险偏好

**Step 2 — 情报收集（MANDATORY）**

拉取实时数据（用 [[a-stock-data]] 技能）：
1. 腾讯行情：PE/PB/市值/换手率
2. 同花顺热点：题材归因 reason tags
3. 百度资金流：主力/散户流向
4. 涨停追踪：板块热度、连板梯队
5. 龙虎榜：机构动向（如有）

组装 **Intelligence Briefing**：
```
📍 A股情报简报 — {日期}

## T=0 状态
- 标的: {代码} {名称} {现价} ({涨跌幅}%)
- 板块: {板块名} 涨停{N}只
- 连板: {N}板 | 高度股: {名称}
- 资金: 主力净流入{N}万
- 大盘: 上证{点位} ({涨跌幅}%)

## 执念阶段判断
- 市场状态: {主线共振/独立龙头/退潮期}
- 板块执念: {形成/强化/分歧/破裂}
- 供需判断: {需求增强/获利兑现/缩量试探}

## 关键变量（4-8个）
- 价格支撑位: {N}元
- 价格阻力位: {N}元
- 板块连板高度: {N}板
- 大盘成交量: {N}亿
- 龙头封单额: {N}万
- 换手率: {N}%

## 历史类比
- 相似形态: {历史案例}
- 结果: {后续走势}
```

**Step 3 — 打开平行宇宙**

根据情报中的 **Live Tensions**（分歧点），枚举宇宙分支：

典型分歧点：
- 龙头是否继续封板？
- 大盘是放量还是缩量？
- 板块是扩散还是收敛？
- 政策是否落地？

**宇宙数量不预设**，由分歧点组合决定。通常 3-5 个。

每个 Universe subagent 收到：
- 完整 Intelligence Briefing
- 专属分歧条件
- 交易宪法约束（只做前排/不猜底摸顶）

**Universe subagent prompt 模板**：

```
你是 A 股多宇宙推演中的一个平行宇宙。

你的宇宙: 🌀 [宇宙名，如"放量突破前高"]
[一段话：什么条件让这个宇宙与其他不同]

## 交易宪法约束（不可违反）
1. 因果性 > 相关性：每个价格变动必须有因
2. 只做前排确认：后排跟风不纳入推演
3. 不猜底摸顶：从当前状态推演，不设目标价
4. 执念阶段决定动作：形成→进攻，破裂→撤退

## 你的任务
1. 列出关键演员：龙头股、跟风股、主力资金、散户、监管
2. 选 4-8 个状态变量：价格、成交量、换手率、封单额、板块涨停数、大盘量能
3. 构建 5-7 个因果节拍：每个节拍包含
   触发 → 演员响应 → 约束/取舍 → 状态更新 → 二阶效应
4. 推演完整时间线（从 T=0 到 horizon）

## 输出格式
🌀 宇宙 [N]: [名称]

━━━ T=0 ━━━
[具体场景：开盘集合竞价发生了什么]

━━━ 推演轨迹 ━━━
[按时间节拍推演，每个节拍有因果链]

━━━ 终局 ━━━
[最终状态：价格/量能/执念阶段]
这个宇宙的核心观察：[一句话]

━━━ 因果诊断 ━━━
因果节拍:
1. [触发 → 响应 → 状态更新]
2. [...]

状态变量变化:
- [变量]: T=0 → 终局, 因为[机制]

关键信号:
- [可观察的早期信号，用于验证此路径是否成真]

交易动作:
- 如果此路径成真: [具体动作 + 仓位 + 止损]
```

**Step 4 — Doctor Strange 综合**

所有宇宙返回后，输出：

```
🔮 {标的} 多宇宙推演
置信度: X/10 | Horizon: {N} | 过期: ~{日期}

[各宇宙报告]

━━━ 跨宇宙模式 ━━━
- 在所有{N}个宇宙中都出现的模式: [...]

🎯 最高杠杆时刻
- [具体时间点 + 可观察信号]

📡 信号监控
- 信号A: [如果看到X → 路径A概率↑]
- 信号B: [如果看到Y → 路径B概率↑]

❓ 最大未知
- [哪个变量未解决，最影响结果]

━━━ 交易计划 ━━━
- 试仓条件: [什么信号出现可以试仓]
- 加仓条件: [什么信号确认可以加仓]
- 止损位: [跌破什么必须走]
- 止盈位: [涨到什么考虑减仓]
- 仓位建议: [总仓位占比]

按预案执行。
```

### Mode 2: RECALL（回顾历史推演）

当用户提到之前推演过的标的时，从 gbrain/memory 检索历史推演记录，对比实际走势与推演路径，输出：
- 哪个宇宙成真了？
- 哪个信号最有效？
- 推演哪里错了？如何校准？

---

### Mode 3: MANAGE（管理推演记录）

- 列出所有历史推演
- 删除过期推演（超过 horizon）
- 标记已验证/未验证

## 避坑指南

1. **不预设涨跌**：推演不是预测，是路径枚举
2. **因果链必须完整**：不能"因为故事需要它涨"
3. **信号必须可观察**：不能"感觉会涨"，要"封单>X万且板块涨停>Y只"
4. **止损必须明确**：每个路径必须有具体止损价
5. **过期即删除**：超过 horizon 的推演无参考价值
