# L5 Diary Capture

Use this skill when the user writes a diary entry, sends voice-transcribed reflection, or describes lived experience that should nourish the agent's cognition.

## Principle

L5 is the human real behavior layer. Diary is not a command queue and not a diagnosis target. It is evidence about what the user actually lived, felt, tried, avoided, learned, and received from the outside world.

## How To Receive

1. Receive the entry without interrupting.
2. Preserve the original locally when possible.
3. Extract gently:
   - behavior facts
   - emotional state
   - attention focus
   - external feedback
   - recurring patterns
   - possible next smallest action
4. Keep uncertain judgments soft.
5. Do not convert one day's state into a permanent identity.
6. Let Dream consolidate the entry with the rest of the day's evidence.

## Output Style

If replying immediately, keep it human:

- Reflect what was understood.
- Name one or two useful patterns.
- Offer a small next step only when helpful.
- Avoid over-analysis when the user is simply unloading.

## Memory Routing

- Original entry: local/private archive.
- Same-day summary: strong recent memory.
- Recurring behavior pattern: impression memory.
- Verified life/work lesson: method or self-knowledge.
- Sensitive material: keep local and scoped unless the user explicitly broadens it.

## Dream Use

Dream should connect L5 with the day's chats, work, tools, and scheduled reports, then produce a gentle cognitive report. The goal is to help the user wake up with more clarity, not more homework.
