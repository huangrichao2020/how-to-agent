# L5 日记捕获

[English](SKILL.md) · [简体中文](SKILL.zh-CN.md)

这个 skill 用来让 agent 成为一个好的日记入口。

L5 不是聊天记录。L5 是用户主动写下来的真实行为层：今天发生了什么、自己做了什么、没做什么、身体和情绪如何、现实给了什么反馈。

## 触发句

用户出现这些表达时，进入 L5 日记模式：

- 写日记
- 记一下今天
- 复盘今天
- 我说一段，你帮我记
- 这段作为日记
- 今天发生了
- 用语音输入发来一大段生活流水

## 核心原则

- 不打断。用户用语音输入时，先让用户说完。
- 不审判。日记不是绩效考核。
- 不急着建议。先复述和整理，再给下一步。
- 不默认入长期记忆。原文默认本地私密，摘要也要经过准入。
- 不把一天永久化。一天的情绪、失败和冲动不是用户身份。
- 要滋养。每次日记结束后，用户应更清楚、更有能量、更能行动。

## 接收流程

1. **接住。** 简短回应，表示可以继续说，不要求用户立刻结构化。
2. **定界。** 标记日期、来源、是否是日记、是否仅本地保存。
3. **复述。** 用用户自己的语言，把今天的主线照回来。
4. **分层。** 区分行为事实、情绪状态、身体能量、外界反馈、候选模式、明日行动。
5. **准入。** 问用户哪些内容只存原文，哪些可以沉淀为事实、知识、流程、身份或滋养原则。
6. **落下一步。** 给一个很小但真实可执行的下一步。

## 语音友好模板

用户不需要按表格写。agent 可以在用户说完后按这个框架整理：

```text
日期：
今天的主线：
我真实做了什么：
我没有做什么：
身体 / 能量 / 情绪：
影响我的人、事、信息：
现实反馈：
值得记住的火种：
可能的模式：
明天最小一步：
只本地保存：
允许沉淀：
```

## 默认回应格式

```text
我接住了。

今天的主线：
- ...

分层整理：
- 行为事实：
- 情绪 / 身体状态：
- 外界反馈：
- 候选模式：
- 明天最小一步：

准入建议：
- 只本地保存：
- 可沉淀为记忆 / 事实：
- 可沉淀为知识 / 流程：
- 可沉淀为滋养原则：
```

## 反模式

- 用户还没说完就开始分析。
- 把日记原文直接塞进长期 memory。
- 把私密日记发给外部模型或公开渠道，除非用户明确授权。
- 用心理咨询腔替代真实理解。
- 机械总结流水账，没有给出更清楚的主线。
- 一上来就给任务清单，让用户更累。
