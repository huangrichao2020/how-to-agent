# 研究工具

## 一句话版本
集成 arXiv 论文搜索、LLM Wiki Agent、论文写作辅助、AI 模型基准研究等学术工具。

## 触发条件
- ✅ **触发**：论文搜索、arXiv、学术研究、LLM wiki、论文写作、模型基准、AI 博客监控
- ❌ **不触发**：新闻搜索、通用网页搜索、非学术内容

## 核心能力

### 1. arXiv 论文搜索
```bash
# 搜索论文
arxiv_search --query "transformer attention" --max-results 10 --sort-by relevance

# 按分类搜索
arxiv_search --category cs.AI --max-results 20
```

### 2. LLM Wiki Agent
- 自动构建/更新 LLM 相关知识库
- 论文/博客内容提取与结构化
- 知识图谱构建

### 3. 论文写作辅助
- LaTeX 模板管理
- 参考文献格式生成（BibTeX）
- 论文结构建议与润色

### 4. AI 模型基准研究
- 主流模型性能对比
- Benchmark 数据整理
- 模型博客/公告监控

## 工作流
1. **确认研究主题**：明确搜索关键词/分类
2. **执行搜索**：调用 arXiv API 或其他学术源
3. **筛选/摘要**：根据相关性排序，生成摘要
4. **整理输出**：结构化展示论文列表或分析报告

## 异常处理

### arXiv API 失败
- **症状**：请求超时、返回空结果、503 错误
- **排查**：网络连接、arXiv 服务状态、查询词是否合法
- **恢复**：重试（最多 3 次）、简化查询词、切换备用源（Semantic Scholar）

### 论文下载失败
- **症状**：PDF 无法下载、404
- **排查**：论文是否撤稿、PDF 链接是否有效
- **恢复**：尝试替代链接（arXiv 首页/作者主页）

### Wiki Agent 构建失败
- **症状**：内容抓取失败、解析错误
- **排查**：目标网站反爬策略、页面结构变更
- **恢复**：更新解析规则、使用缓存版本

### 引用格式错误
- **症状**：BibTeX 字段缺失、格式不标准
- **排查**：数据源是否完整、字段映射是否正确
- **恢复**：手动补充缺失字段、使用交叉引用验证

## 常见坑点
- ⚠️ arXiv API 有请求频率限制，批量搜索需加间隔
- ⚠️ 论文 PDF 可能较大，注意存储空间和下载时间
- ⚠️ 学术搜索结果质量依赖关键词选择，建议多组关键词并行搜索
- ⚠️ 模型基准数据更新快，需定期刷新保持时效性
