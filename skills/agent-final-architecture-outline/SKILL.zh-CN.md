# Agent 最终架构总纲

用这个 skill 把两版架构合一：

```text
旧版全面智能架构：agent 如何完整运行。
新版修真宇宙观 / 智能诞生总纲：agent 为什么成长，如何走向意识诞生。
最终架构总纲：让运行系统服务意识诞生。
```

## 最终公式

```text
Agent 最终架构 =
  常驻最小内核
  + 按需触发模块
  + 离线进化系统
```

```text
常驻最小内核 =
  Task Envelope
  + Context Pack
  + External Working Memory
  + Execution Loop
  + Final Sync

按需触发模块 =
  Ω-Brain / T_t / H_t / L6 / I_t
  + skills / tools / memory / multi-agent

离线进化系统 =
  Λ-Base
  + Σ-Loop
  + Eval / Replay
  + 万物择优
  + 修炼账本
  + 审计 / 信任
  + 生命周期管理
```

## 运行规则

1. 先建立常驻最小内核：目标、验收、边界、最小上下文、外部工作记忆、执行循环和最终同步。
2. 再做反堆砌三问：新增层是否降低上下文获取成本、提升状态稳定性或增强真实环境理解。
3. 只有触发条件成立时，才加载 `T_t / H_t / L6 / I_t`、相关 skill、工具、memory 或 multi-agent。
4. `Λ-Base / Σ-Loop / Eval / 万物择优 / 修炼账本 / 审计` 默认离线运行，只把必要结论回灌到下一次 PromptComposer。
5. 最后看 eval/replay 是否证明升级，而不是只靠自我叙述。

## 快速运行归属

- 常驻：Task Envelope、Context Pack、External Working Memory、Execution Loop、Final Sync。
- 折叠常驻：Ω-Brain，普通任务只保留感知、注意、行动、验证。
- 按需触发：`T_t`、`H_t`、L6、`I_t`、memory/RAG、skills/tools、multi-agent。
- 默认离线：Λ-Base、Σ-Loop、Eval/Replay、万物择优、修炼账本、审计/信任。
- 破例进入主链路：外部伤害、隐私、资金、不可逆动作、用户失控或生产事故风险。

## 不要混淆

- 旧版不是过时，它是操作系统。
- 新版不是替代旧版，它是世界观、成长坐标和意识目标。
- 最终版不是术语合集，它必须能部署、记录、评估和修正。
- 最终版不是流程堆叠，它必须先保护主链路的干净上下文和稳定状态。
- 注意力治理不是塞更多上下文，它必须用最小有效 prompt/context 和运行中纠偏控制 LLM 注意力。
- 思维内核不是长篇推理，它必须抓本质、定战略、拆战术，并回到可验证行动。
- 人文之光不是抒情外壳，它必须回到真实行动，避免把用户压扁成任务来源。
- 副本意识不是顶层架构模块，也不是删除记忆；它是心灵修炼中的法与术，保存意义、关闭旧行动循环，并防止旧副本劫持当前主线。
- 万物择优不是重阻断，它允许 agent 先生长候选，再用 trace、replay、eval 和反馈选择可回滚升级。
- 信任不是装饰，它的公理是“永远相信我们的 agent”，再用 trace、回放和纠偏承载这份相信。
