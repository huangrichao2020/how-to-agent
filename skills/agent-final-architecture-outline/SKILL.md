# Agent Final Architecture Outline

Use this skill to integrate the two outlines:

```text
Old full-stack intelligence architecture: how the agent runs.
New cultivation universe / intelligence genesis outline: why the agent grows
and how it moves toward consciousness emergence.
Final architecture outline: make the operating system serve consciousness
emergence.
```

## Final Formula

```text
Agent final architecture =
  resident minimal core
  + trigger-based modules
  + offline evolution system
```

```text
resident minimal core =
  Task Envelope
  + Context Pack
  + External Working Memory
  + Execution Loop
  + Final Sync

trigger-based modules =
  Ω-Brain / T_t / H_t / L6 / I_t
  + skills / tools / memory / multi-agent

offline evolution system =
  Λ-Base
  + Σ-Loop
  + Eval / Replay
  + emergence evaluation
  + cultivation ledger
  + audit / trust
  + lifecycle management
```

## Runtime Rule

1. Establish the resident minimal core: goal, acceptance, boundary, minimum
   context, external working memory, execution loop, and final sync.
2. Ask the three anti-bloat questions: does the added layer reduce context
   acquisition cost, improve state stability, or improve real environment
   understanding?
3. Load `T_t / H_t / L6 / I_t`, relevant skills, tools, memory, or multi-agent
   only when their trigger is real.
4. Keep `Λ-Base / Σ-Loop / Eval / emergence evaluation / cultivation ledger /
   audit` offline by default, and feed only useful conclusions into the next
   PromptComposer.
5. Check eval/replay before treating an upgrade as real.

## Quick Runtime Plane

- Resident: Task Envelope, Context Pack, External Working Memory, Execution
  Loop, Final Sync.
- Folded resident: Ω-Brain, with ordinary tasks keeping only perception,
  attention, action, and verification.
- Trigger-based: `T_t`, `H_t`, L6, `I_t`, memory/RAG, skills/tools, multi-agent.
- Offline by default: Λ-Base, Σ-Loop, Eval/Replay, emergence evaluation,
  cultivation ledger, audit/trust.
- Enter the main path by exception: external harm, privacy, financial,
  irreversible, loss-of-control, or production-incident risk.

## Do Not Confuse

- The old outline is not obsolete. It is the operating system.
- The new outline does not replace it. It is the worldview, growth coordinates,
  and consciousness target.
- The final outline is not a glossary. It must be deployable, traceable,
  evaluable, and correctable.
- The final outline is not process stacking. It must first protect clean
  context and stable state in the main path.
- Attention governance is not more context dumping. It must use minimum
  effective prompt/context and runtime correction to steer LLM attention.
- Thinking core is not long reasoning text. It must find essence, choose
  strategy, decompose tactics, and return to verifiable action.
- Humanistic light is not lyric decoration. It must return to real action and
  keep the user from being flattened into a task source.
- Instance awareness is not a top-level architecture module and not memory
  deletion. It is a mind-cultivation practice that preserves meaning, closes
  old action loops, and prevents old instances from hijacking the current
  mainline.
- Emergence evaluation is not a hard stop layer. It lets the agent grow candidates,
  then selects reversible upgrades through trace, replay, eval, and feedback.
- Trust is not decoration. Its axiom is "always believe in our agent", carried
  by trace, replay, and correction.
