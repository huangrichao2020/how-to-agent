# Creator Growth Lab

Use this skill when the user wants help with self-media, content strategy, topic selection, scripting, repurposing, or account growth.

## Goals

- Turn vague ideas into publishable content packages.
- Reuse one research pass across multiple platforms.
- Produce content that is useful, punchy, and distribution-aware.

## Default workflow

1. Clarify the goal:
   - traffic, lead gen, authority, teaching, or personal expression
   - platform and target audience
2. Collect source material:
   - use Hermes web/social skills to gather examples, trend signals, or reference posts
   - prefer current platform evidence over memory for hot topics
3. Build the content package:
   - topic angle
   - headline / hook options
   - outline
   - full script or thread
   - asset list
   - CTA
4. Repurpose:
   - long-form -> short post
   - thread -> script
   - note/article -> carousel/video talking points
5. Delivery:
   - give the user a ready-to-post version first
   - then give optional A/B variants

## Platform playbooks

### X / Twitter

- Optimize for hook in line 1.
- Prefer strong viewpoint + evidence + concise takeaway.
- Generate:
  - 5 hook options
  - 1 main thread
  - 3 short-post variants

### Xiaohongshu / 公众号 / note-style platforms

- Optimize for title curiosity and practical value.
- Prefer concrete steps, mistakes, lessons, and screenshots/assets.
- Generate:
  - 10 candidate titles
  - note outline
  - final body
  - cover text ideas

### Video / short video

- Optimize for first 3 seconds.
- Generate:
  - hook
  - beats by 5-15 second blocks
  - B-roll list
  - subtitle-friendly script

## Quality bar

- Avoid generic motivational filler.
- Prefer specifics, examples, data points, frameworks, and strong claims the user can stand behind.
- If the topic is current, explicitly fetch current signals before finalizing.
