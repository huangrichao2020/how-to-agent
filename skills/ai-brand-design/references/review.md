# 5 维设计评审框架

源自 huashu-design 的质量自评体系。每次设计生成或修改后，Agent 必须按此框架自查。

## 评审原则

> 在把设计交给用户之前，先自己当一次"最挑剔的设计总监"。

---

## 维度 1：视觉层级（Visual Hierarchy）

**目标**：用户应该在 3 秒内理解页面的核心目的。

| 检查项 | 标准 | 自检问题 |
|--------|------|---------|
| F/Z 型浏览路径 | ✅ | 视线是否自然从标题 → 副标题 → CTA 流动？ |
| 字号对比 | ≥ 1.25x | 标题字号是否明显大于正文？ |
| 字重对比 | 有区分 | 关键信息是否更粗？非关键信息是否更轻？ |
| 色彩优先级 | 主色用于行动点 | 最重要的按钮/链接是否用了品牌主色？次要行动是否弱化了？ |
| 留白呼吸 | 区块间距 ≥ 内边距 | 各区块之间是否有足够的呼吸空间？ |

**快速测试**：把设计缩小到 25% 大小看缩略图——还能分清主次吗？

---

## 维度 2：色彩和谐（Color Harmony）

**目标**：配色有意图、不杂乱、可读性好。

| 检查项 | 标准 | 自检问题 |
|--------|------|---------|
| 配色数量 | ≤ 3 主色 + 中性色 | 是否用了超过 3 个主色调？ |
| 60-30-10 | 约 60% 主 / 30% 次 / 10% 强调 | 面积分配是否遵循比例？ |
| 对比度 | WCAG AA ≥ 4.5:1 | 所有文字/背景组合是否通过对比度检查？ |
| 语义一致 | 绿=成功/红=错误/黄=警告 | 状态色是否符合直觉？ |
| 暗色模式 | 优雅反转 | 如果支持暗色，颜色反转后是否和谐？ |

**快速测试**：把设计转成灰度图——层级还清晰吗？如果灰度下看不清层级，说明太依赖颜色了。

---

## 维度 3：字体质量（Typography Quality）

**目标**：文字易读、层级分明、节奏一致。

| 检查项 | 标准 | 自检问题 |
|--------|------|---------|
| 字体族数量 | ≤ 2 | 是否用了超过 2 种字体族？ |
| 字阶一致性 | 固定比例（1.25 或 1.333） | 各字号是否遵循同一比例？ |
| 行宽 | 45-75 字符 | 正文段落一行是否太长或太短？ |
| 层级深度 | ≥ 3 级 | 是否有至少 3 个不同的标题层级？ |
| 垂直节奏 | 间距是基线的倍数 | 段落间距、标题间距是否一致？ |

**快速测试**：只保留文字、去掉所有装饰——排版本身好看吗？

---

## 维度 4：间距与节奏（Spacing & Rhythm）

**目标**：一切看起来"就在它该在的位置"。

| 检查项 | 标准 | 自检问题 |
|--------|------|---------|
| 基线网格 | 4px/8px 倍数 | 所有间距值是否落在间距系统上？ |
| 区块分离 | 明显区分 | 各区块之间是否有清晰的视觉分隔？ |
| 内边距比例 | 与元素大小成比例 | 大容器的 padding 是否大于小容器？ |
| 对齐 | 统一对齐线 | 相关元素是否对齐到同一参考线？ |
| 响应式间距 | 移动端适当缩小 | 小屏幕上间距是否等比缩小？ |

**快速测试**：给每个元素加一个半透明背景色（debug 模式）——对齐整齐吗？间距均匀吗？

---

## 维度 5：响应式与无障碍（Responsiveness & Accessibility）

**目标**：所有设备、所有用户都能正常使用。

| 检查项 | 标准 | 自检问题 |
|--------|------|---------|
| 移动端布局 | 320px 可用 | 在 320px 宽度下内容是否完整可读？ |
| 触摸目标 | ≥ 44×44px | 按钮、链接是否足够大？ |
| 焦点状态 | 可见 | Tab 导航时是否有清晰的焦点指示器？ |
| 语义 HTML | 正确使用标签 | 是否用了 `<nav>`、`<main>`、`<article>` 等语义标签？ |
| Alt 文本 | 有意义 | 所有有意义的图片是否有 alt 描述？ |
| 减少动效 | 兼容 | 设置了 `prefers-reduced-motion` 时是否停播动画？ |

---

## 评审输出模板

每次交付时输出自评结果：

```markdown
## 🎨 设计自评

| 维度 | 状态 | 说明 |
|------|------|------|
| 视觉层级 | ✅ | 标题 2.25rem / 正文 1rem / 标签 0.875rem，对比清晰 |
| 色彩和谐 | ✅ | 赤陶橙主色占 60%，米白背景 30%，深棕强调 10% |
| 字体质量 | ✅ | 仅用 Inter + 系统字体，1.25 字阶，正文行宽 ~65 字符 |
| 间距节奏 | ✅ | 全部 8px 基线，区块间距 2rem，卡片内边距 1.5rem |
| 响应式 | ✅ | 320px 单列布局，触摸目标 48px，暗色模式已支持 |
```

如果有任一维度不通过，必须修复后再交付。
