# A 股全栈数据
## 一句话版本
A 股数据获取→分析→涨停追踪的端到端工具包。多数据源降级、本地缓存优先、频控严格。

## 数据源优先级
1. 腾讯行情 API (qt.gtimg.cn) — 实时行情，最稳
2. 复盘盒子 API — 涨停/板块/消息
3. MX API (东方财富) — 涨停/资金流 (20次/天)
4. Baostock — 历史 K 线/财务 (Parquet 缓存)

## 涨停追踪
- 龙头/身位/跟风/高度股识别
- reason 字段优先于行业分类

## 反模式
- 用 yfinance 查 A 股 → 不支持
- 一次性查全市场 → OOM
- 非交易时段查实时 → 昨日收盘
- 不设频控 → 配额耗尽
