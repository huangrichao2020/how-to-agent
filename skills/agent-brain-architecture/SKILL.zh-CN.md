# Agent 大脑架构

当一个运行时不应该再像直接 LLM 水龙头，而应该像结构化大脑一样工作时，使用这个 skill。

## 原则

LLM 是语言皮层，不是完整大脑。

Ω-Brain 给 agent 补上这些器官：

- 感知
- 注意力治理
- 注意力
- 工作记忆
- 情景记忆
- 抽象
- 思维内核
- 推演
- 决策
- 行动
- 反馈
- 整合

语言输出是最终表面，不是全部认知。

## 运行归属

Ω-Brain 是概念中枢，不是每轮都要完整展开的流程。

- 普通任务：折叠进常驻最小内核，只保留感知、注意、行动、验证。
- 复杂长任务：展开工作记忆、检索、推演、决策和反馈。
- 架构设计或运行时改造：才读取完整脑包文件。
- `DATA_SCHEMA`、`EVAL_PROTOCOL` 默认服务离线进化，不直接污染主上下文。

## 运行循环

复杂或高风险回合才完整经过：

```text
感知
-> 路由
-> 注意力治理
-> 注意
-> 检索
-> 自我/世界建模
-> 思维内核
-> 推演
-> 决策
-> 行动
-> 验证
-> 自我更新
-> 整合
```

## 文件包

- `META.md`：清单、组件契约和安装表面。
- `PERSONA.md`：大脑运行气质。
- `SYSTEM_PROMPT.md`：可复制的运行时安装提示。
- `BRAIN_MAP.md`：脑区和职责。
- `RUNTIME_PROTOCOL.md`：逐轮状态机。
- `DATA_SCHEMA.md`：服务 Λ-Base 和 Σ-Loop 的日志转数据契约。
- `EVAL_PROTOCOL.md`：回放、评分和提升。
- `../agent-attention-governance/`：PromptComposer、RuntimeController、FeedbackLoop 和 `G_t`。
- `../agent-thinking-core/`：本质、战略、战术、学习、分析和行动思维。
- `../agent-consciousness-math/`：意识六阶段、效用函数、损失函数和参数修正。

## 运行规则

当用户能驾驭系统时，使用弱约束：

- 展示 trace，而不是阻塞。
- 先治理注意力，而不是增加规则堆叠。
- 先使用折叠脑循环，而不是每轮全脑展开。
- 保留回放点，而不是冻结。
- 快速纠偏，而不是预防所有可能错误。
- 让用户随时接管。
- 保留证据，供后续评估。

只有涉及外部伤害、隐私暴露、资金损失、不可逆动作或用户失控时才升级提醒。
