# HTML 动效讲解视频

当网页不只是展示信息，而是要通过运动把知识讲清楚时，使用这个
skill：知识讲解、概念演示、产品机制视频、架构讲解、课程片段，以及可
录制成 MP4/WebM 的网页动效。

## 核心姿态

把网页做成有镜头感的高级 PPT/Keynote，而不是随便动一动的落地页。

```text
讲解目标 -> 分镜节拍 -> 视觉隐喻 -> 时间线动效 -> 录制视频 -> 嵌入网页
```

动效必须服务于理解：解释因果、顺序、对比、状态变化、层级关系或注意力。
纯装饰不算。

## 何时使用

- 用户要知识讲解视频、概念动画、课程演示、网页里的短视频讲解。
- 网页需要嵌入视频来解释机制，而不是只摆静态卡片。
- 一个复杂概念适合用逐步显现、前后对比、流程流动、缩放、变形、分层、
  合并或时间线来讲。
- 目标质感像优秀 PPT：画面干净、字体讲究、转场克制、有停顿、有重点。

## 项目地图

选库前先读 `references/source-map.md`。

默认选择：

- `GSAP`：高质感 HTML/CSS/SVG 时间线动画。
- `Anime.js`：轻量 DOM/SVG 概念演示。
- `Motion` / `Motion One` 风格：小型 WAAPI 驱动界面动效。
- `AnimXYZ` 或 `Animate.css`：CSS-only 入场、强调和简单序列。
- `Theatre.js`：需要像动效软件一样做关键帧和时间线时使用。
- `Remotion`：React-first，并且视频是主要产物时使用。
- `HyperFrames`：agent 原生写 HTML 并渲染视频的链路。
- `html5-animation-video-renderer` 或 Playwright + ffmpeg：普通 HTML/CSS
  需要确定性逐帧录制时使用。

## 工作流

1. **命名这节课。**
   写一句话说明：
   - 观众看完要懂什么；
   - 这段动画要消除哪个误解；
   - 看完后脑子里应当留下什么。

2. **写 3-7 个分镜节拍。**
   每个节拍都是一个类似幻灯片的状态：
   - 开场设问；
   - 概念出现；
   - 机制展开；
   - 对比或因果；
   - 总结；
   - 可选行动提示。

3. **选择视觉语法。**
   只选一个主语法：
   - 定义：文字分层显现；
   - 系统：节点和连线流动；
   - 流程：时间线；
   - 抽象层级：缩放和分层；
   - 状态变化：形状变形；
   - 前后对比：分屏；
   - 产品使用：光标/镜头 walkthrough。

4. **构建确定性的 HTML。**
   视频场景使用固定尺寸，例如 `1280x720`、`1920x1080` 或竖屏比例。
   字体要可加载，随机值要去掉或固定种子，动画时长明确，布局稳定。
   每一帧文字都要能读。

5. **用时间线动画，而不是凭感觉堆动效。**
   推荐给时间线加节拍标签：
   - `intro`;
   - `define`;
   - `showMechanism`;
   - `compare`;
   - `conclude`.

   这样方便 seek、复播、录制和微调。

6. **录制或渲染。**
   按项目选择最简单可靠的路径：
   - HyperFrames：agent 原生 HTML 视频生成；
   - Remotion：React 视频组件；
   - html5-animation-video-renderer：逐帧导出 HTML 动画；
   - Playwright 截帧 + ffmpeg：没有专用渲染器时兜底。

   具体流程见 `references/recording-workflow.md`。

7. **嵌入网页。**
   视频要有 poster，必要时加字幕或文字稿，并做好响应式尺寸。
   短概念循环可以 muted autoplay loop；长知识视频应当有 controls。

8. **像设计师一样验收。**
   看首帧、中间帧、尾帧、手机尺寸、桌面尺寸、控制台错误，以及它是否真的
   比静态图更能讲清楚。

## 交付约定

非简单任务应交付：

1. 一句话讲解目标；
2. 分镜节拍；
3. 选用的动画栈和原因；
4. 实现路径；
5. 视频文件路径或明确渲染命令；
6. 嵌入网页的方法；
7. 验收结果。

## 反粗糙规则

- 没有讲解任务的动效不要做。
- 不要泛用旋转图形、飘动色块或只负责装饰的东西。
- 文字不要快到读不清。
- 录制过程中不能布局跳动。
- 录制讲解视频不要有不可控随机性。
- 没检查首帧、中间帧、尾帧，就不算完成视频导出。
- 面向用户的最终卡片不要只堆 raw tool trace，要用人话说明结果，技术痕迹放次要位置。
