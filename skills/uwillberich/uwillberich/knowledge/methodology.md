### 核心纪律（不可违反）

1. **先定方法论，再调工具**
   → 先用 uwillberich 判断市场状态，再决定调哪个 Skill

2. **数据为辅，逻辑为主**
   → Skills 返回的数据要经过五步分析法过滤

3. **绝不因数据好看而改变市场状态判断**
   → 市场状态由结构和逻辑决定，不是由数据决定

4. **Skill 结果与 uwillberich 冲突时 → 信 uwillberich**
   → 工具是感官，方法论是大脑

## 一、核心方法论

### 基本逻辑链

```
事件破圈 → 大资金关注 → 板块启动 → 散户涌入 → 流动性充裕 → 拉高出货
```

所有分析都必须服务于这条链条。

**判断的核心问题永远是：「这个事件有没有破圈的可能？」**

### 破圈判断标准

| 维度 | 破圈信号 | 非破圈信号 |
|------|----------|------------|
| **传播范围** | 全网热搜/官媒报道 | 仅小众交易圈讨论 |
| **资金规模** | 板块成交>500 亿 | 仅个别票放量 |
| **持续时间** | 持续 3 天以上 | 一日游 |
| **板块共振** | 10+ 股涨停 | 单一龙头 |

---

## 二、主线行情判断标准

触发以下任意一条 = 主线信号：
- 国家级会议/文件点名的发展方向
- 多部委联合发文（两个部委以上）
- 全国性重大事件（政策突变/重大冲突/社会焦点）
- 全球性重大事件（影响世界的冲突/灾难/技术革命）

**主线确认标准**：板块内同时出现 10 个以上个股涨停或集中大买单

---

## 三、独立龙行情判断标准

- 只有 1~3 只票脱离板块单独拉升，板块其他票无明显联动
- 无明显政策催化，量能持续放大
- 触发来源：重组/资产注入/业绩超预期/季节周期/大宗涨降价

---

## 四、震荡市判断标准

- 无主线、无独立龙
- 涨停家数低于 40 家
- 板块资金分散，无明显方向

---

## 五、三种持仓类型

### SHORT 短线（次日抢跑）

满足以下特征才归为 SHORT：
- ✓ K 线直线拉升，角度陡峭（>70 度）
- ✓ 单日成交量异常放大（明显非自然买盘，量化资金行为）

**操作**：次日开盘高位减仓离场，不恋战，不过夜

### MID 中线（趋势跟随）

满足以下特征才归为 MID：
- ✓ 不涨停但连续上涨，趋势良好
- ✓ 量能温和放大，无单日异常峰值

**操作**：跟随主力高抛低吸，震荡吸筹
**止损**：跌破 15 分钟图 MA20 线触发

### LONG 长线（价值低估）

满足以下特征才归为 LONG：
- ✓ 基本面优质，经常分红
- ✓ 股价低于 MA120 日线的 90% 时开始建仓
- ✓ 越低越买

**目标**：股价上涨至 MA120 日线×120% 时卖出

## 六、市场策略分类

| 行情类型 | 策略类型 | 需要的数据 |
|----------|----------|------------|
| 中线行情 | 趋势跟随型 | 量价结构、板块轮动数据 |
| 短线非主线抱团行情 | 事件驱动型 | 公告、政策、财报节奏 |
| 短线主线行情 | 情绪博弈型 | 北向资金、龙虎榜、舆情热度 |

## 七、独立行情六大触发模板

### 模板 A：重组注入热门资产
- **特征**：ST 股/小市值 + 跨界 AI/芯片/算力
- **持仓**：SHORT，公告当日进，3~5 个板离场
- ⚠️ 不在股票池范围内，仅用于识别市场情绪高度

### 模板 B：硬科技产业链景气共振
- **特征**：有真实订单/业绩 + 对应英伟达/华为/特斯拉/SpaceX 链
- **持仓**：MID，跟随产业链景气度，止损用 MA20
- ✅ 股票池主要覆盖此类

### 模板 C：玄学/名字炒作
- **特征**：名字含生肖/寓意 + 低市值 + 无基本面
- **持仓**：不参与，仅作为市场情绪温度计
- **规律**：生肖年前 1 个月开始炒作，连板超 10 个换手骤降则见顶

### 模板 D：大宗商品涨价
- **特征**：产品价格暴涨 + A 股上游对应标的
- **持仓**：SHORT 到 MID，视涨价持续性决定
- **触发**：上海钢联报价异常拉升时立刻触发扫描

### 模板 E：地缘/政策强事件
- **特征**：国家级事件 + 地域/行业直接受益
- **持仓**：MID，事件发酵期跟随高抛低吸

### 模板 F：次新股无套牢盘
- **特征**：上市 3~6 个月内 + 市值低于 30 亿 + 题材契合
- **持仓**：不参与，风险超出仓位管理范围

## 九、强日期锚定事件规则

### 判断标准
- ✓ 有明确的、公开的、不可更改的日期
- ✓ 稀缺性高（十年一次 > 每年一次 > 随机事件）
- ✓ 全国/全球关注度

### 常见类型
阅兵 / 重大纪念日 / 奥运会 / 世博会 / 重大外交峰会

### 操作逻辑
- 事件公布后 → 立刻识别受益板块 → 中线埋伏辨识度最高的龙头
- 越接近日期情绪越强 → 日期当天或前一天考虑减仓

---

## 十、地缘事件受益资产识别框架

地缘事件发生后，**不要买最直觉的板块，要找第二层逻辑**：

| 层级 | 案例 | 特点 |
|------|------|------|
| 第一层（直觉层） | 台海冲突→军工 / 俄乌冲突→能源军工 | 竞争者最多，溢价最低 |
| 第二层（逻辑层） | 台海统一预期→福建/平潭 / 俄乌停火→重建材料 | 竞争者少，溢价更高 |

### 判断标准
- ✓ 辨识度高（名字/地理/政策直接相关）
- ✓ 散户能看懂逻辑（破圈条件）
- ✓ 大资金有理由长期持有（不是一日游）

---

## 十一、事件类型与持仓策略对应

### 有结束日期的事件（阅兵/奥运/大会）
- **策略** = 提前埋伏 + 日期前减仓
- **退出信号** = 日期临近，情绪见顶

### 无结束日期的事件（地缘冲突/政策持续）
- **策略** = 事件确认后跟进 + 情绪高抛低吸
- **退出信号** = 官方态度软化 / 板块量能萎缩 / 换手率骤降

---

## 十二、妖股退出硬规则

- 连板超过 10 个且换手骤降 → 次日开盘强制减仓
- 监管介入停牌核查 → 复牌日高开减仓
- 同板块出现更强新龙头 → 切换，不恋旧标的

### 妖股寿命参考
- 重组类/玄学类 → 3 周内
- 科技产业链/地缘事件 → 1~2 个月
- 周期涨价/真实业绩 → 2 个月以上

### 历史妖过的股票池内标的
胜宏科技 / 新易盛 / 工业富联 / 张江高科 / 润和软件
（再次启动需确认新催化剂）

---

## 十三、仓位与止盈止损规则

- 建仓：2 万
- 加减仓：每次 1 万（买卖均控制在 1 万）
- 止盈：+15%

### 止损规则
- 跌破 15 分钟图 MA20 线 → 先减半仓
- 继续跌 → 继续减
- 上穿 MA20 线 → 重新加回

| **主线确认** | 问财选板块、行业数据查询 | 板块涨幅、主力流入、涨停家数 |
| **独立龙识别** | 基本资料查询、公司经营数据查询 | 个股独立性、基本面 |
| **事件破圈判断** | 新闻搜索、事件数据查询、捕捉公司事件机会 | 事件传播度、关注度 |
| **五步分析** | 财务数据查询、产业链解读、竞争格局分析 | 基本面深度数据 |
| **仓位决策** | 市场情绪偏离分析、财报前瞻 | 情绪位置、业绩预期 |

### 核心纪律

```
1. 先定市场状态，再调 Skills
   → 主线市场才用问财选板块追强
   → 防御市场用问财选 A 股找低估值

2. Skill 数据必须经过五步分析法过滤
   → 不是数据好就买，是逻辑通才买

3. 绝不因 Skill 数据好看而改变市场状态判断
   → 板块涨 5% 但广度差 = 依然是防御市

4. Skill 结果与 uwillberich 冲突时，信 uwillberich
   → 问财显示强，但市场结构弱 = 不信数据
```

## 十五、历史案例库

### 案例 001 | 2025 年 8 月 | 九三大阅兵 | 军工主线

| 项目 | 内容 |
|------|------|
| 事件定性 | 超大规模国家级事件，十年一次 |
| 触发条件 | 主线第 3 条（超大规模事件） |
| 标的 | 长城军工、华胜天成 |
| 持仓类型 | MID 中线趋势跟随 |
| 周期 | 约一个半月 |
| 结果 | 翻 3 倍 |

**关键判断点**：
1. 十年一次 → 破圈能力极强
2. 有明确结束日期 → 提前埋伏，日期前减仓
3. 板块多股联动 → 确认为主线非独立龙

**未来触发信号**：重大阅兵/演习预告、国防预算超预期、重大国际军事冲突
**对应池内标的**：三角防务、天箭科技、新余国科、中航光电、光启技术、中信海直

---

### 案例 002 | 2025 年 9-10 月 | 台海局势 | 福建/平潭板块

| 项目 | 内容 |
|------|------|
| 事件定性 | 超大规模地缘政治事件 |
| 触发条件 | 主线第 4+5 条（冲突 + 全球关注） |
| 标的 | 平潭发展 + 福建板块个股集体 |
| 持仓类型 | MID 事件持续发酵型 |
| 周期 | 约两个月 |
| 结果 | 集体爆发 |

**关键判断点**：
1. 无结束日期 → 跟随情绪高抛低吸
2. 平潭辨识度极高
3. 第二层逻辑 → 不买军工，买受益于统一的经济资产

**未来触发信号**：官媒"统一""台湾回归"关键词、台海行动升级、平潭自贸区政策
**建议**：单独建立"地缘政治受益组"补充到股票池
