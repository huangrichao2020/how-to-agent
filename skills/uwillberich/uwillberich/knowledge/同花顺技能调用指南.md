## 🔧 常见问题

### Q1: 技能调用失败怎么办？

**检查清单**:
1. 环境变量是否配置
   ```bash
   echo $IWENCAI_BASE_URL
   echo $IWENCAI_API_KEY
   ```
2. API Key 是否有效
3. 网络是否通畅

### Q2: 如何批量调用多个技能？

**建议**: 创建 Python 脚本封装调用逻辑
```python
# 示例：morning_scan.py
from iwencai_client import query

def morning_scan():
    news = query("新闻搜索", keywords=["美联储", "油价"])
    indices = query("指数数据查询", symbols=["纳斯达克", "标普 500"])
    macro = query("宏观数据查询", indicators=["CPI", "非农"])
    futures = query("期货期权数据查询", symbols=["原油", "黄金"])
    
    return generate_report(news, indices, macro, futures)
```

### Q3: 如何集成到 CoPaw 定时任务？

```bash
# 创建 cron 任务
copaw cron create \
  --schedule "30 8 * * 1-5" \
  --command "python /path/to/morning_scan.py" \
  --agent-id default

# 查看任务
copaw cron list --agent-id default
```
