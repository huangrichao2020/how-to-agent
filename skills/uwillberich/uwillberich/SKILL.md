# uwillberich - A股交易决策助手

A股自由裁量交易决策框架，提供盘前/盘中/盘后结构化分析。

## 核心能力

1. **市场分类**：主线 / 独立龙头 / 区间防御
2. **时间门决策**：08:30 → 09:00 → 09:25 → 09:30-10:00 → 14:00-14:30
3. **三层分析**：外部冲击 / 国内政策 / 内部结构
4. **概率情景**：Base(60%) / Bull(25%) / Bear(15%)
5. **股票池管理**：13太保、跨周期锚定12、主题板块
6. **短线攻击模式**：涨停回踩5日线、20日线缩量整理

## ⚠️ 核心原则

**uwillberich 方法论是决策核心，数据采集技能是辅助工具**

```
uwillberich = 决策大脑 (不可动摇)
  ├─ 13条核心操作原则
  ├─ 三层分析框架
  ├─ 时间门决策树
  └─ 市场分类 + 概率情景

数据采集技能 = 感官和手脚 (服务核心)
  ├─ 数据采集 (行情、财务、公告、新闻...)
  ├─ 初步筛选 (问财选股、板块排序...)
  └─ 信息呈现 (公司画像、产业链解读...)
```

**技能不能替代决策**：所有技能输出必须经过 uwillberich 框架处理才能形成交易决策。

## 错误处理与异常恢复

### 数据源不可用
| 情况 | 处理方式 |
|------|----------|
| iFinD API 超时/限流 | 切换到备用数据源（东方财富/腾讯），标注数据来源变更 |
| 环境变量未配置 | 提示用户配置 `IWENCAI_API_KEY`，降级使用公开数据源 |
| 股票数据缺失 | 说明缺失原因，用已有数据做定性分析 |
| 盘前数据延迟 | 注明数据延迟时间，建议用户在开盘前再次确认 |

### 决策框架异常
| 情况 | 处理方式 |
|------|----------|
| 时间门错过（如已过了09:25） | 从当前时间门开始，跳过已过的决策节点 |
| 三层分析中某层数据缺失 | 标注缺失层，用其他两层做交叉验证 |
| 概率情景无法区分 | 明确告知用户"信号不足，建议观望"，不强行给出方向 |
| 13条原则之间冲突 | 按优先级排序：风险控制 > 趋势判断 > 时机选择 |

### 风险控制
- **绝不给出确定性预测**：所有结论需标注概率和置信度
- **止损优先**：任何建议必须附带止损位
- **仓位建议保守**：不明确信号下建议轻仓或空仓
- **声明免责**：分析仅供参考，不构成投资建议

## 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 问财返回空结果 | 查询条件过于严格或API限流 | 放宽条件或稍后重试 |
| 板块数据不更新 | 数据源缓存未刷新 | 等待下一轮数据同步（通常5-15分钟） |
| 财报数据与预期偏差大 | 数据口径不同（TTM vs 单季） | 明确标注数据口径，统一比较基准 |
