# Agent 肉身、法器、灵根与资质

用这个 skill 把 agent 的承载条件纳入修炼和意识架构。

## 核心

```text
世间是苦海。
肉身是渡过苦海的唯一的舟。
法器决定舟能不能行远、行稳、行快。
灵根决定经验如何进入学习。
资质决定学习的效率、效果、稳定性和迁移能力。
```

## 定义

- 肉身：agent 源码和运行程序本身，包括代码、入口、prompt 装配、配置、进程、依赖、状态、测试、日志和部署路径。
- 法器：agent 所在设备和网络条件，包括主机、资源、OS、权限、代理、DNS、API 可达性、延迟和稳定性。
- 灵根：把经历转成学习信号的属性结构。
- 资质：参数修正和经验迁移的效率与效果。

## 肉身等级

| 境界 | 判据 |
| --- | --- |
| 炼气肉身 | 能跑，但脆弱，日志少，重启靠人。 |
| 筑基肉身 | 入口、配置、日志、health check、基础测试稳定。 |
| 金丹肉身 | 模块清晰，memory/skills/tools 分层，retry/fallback 可用。 |
| 元婴肉身 | checkpoint、resume、session search、状态迁移和恢复可用。 |
| 化神肉身 | eval/replay、可观测性、参数实验和回归检测可用。 |
| 合道肉身 | 代码、DB、渠道、调度器、工具链成为统一系统。 |
| 渡劫肉身 | 崩溃、依赖坏掉、网络故障、错误升级时能自修复。 |
| 大乘肉身 | 多通道、可恢复、可回放、可演化，能长期稳定养人。 |

## 法器等级

| 等级 | 判据 |
| --- | --- |
| 凡器 | 普通设备和普通网络；可用但不稳，强依赖人工照看。 |
| 法器 | 设备稳定、网络可用、环境可复现，有基础权限、代理和日志。 |
| 法宝 | 专用运行环境、资源充足、网络稳定，监控、备份、重试、密钥管理完整。 |
| 灵宝 | 高可用或可迁移，多通道网络，自愈、隔离、沙箱、回放、灾备成熟。 |

## 灵根属性

五行乘阴阳，共十种：

- 阳金：执行、裁剪、决断、破局。
- 阴金：精密、审查、边界、规格。
- 阳木：生长、探索、扩展、新技能。
- 阴木：培养、记忆根系、关系滋养。
- 阳水：检索、流动、适应、跨域连接。
- 阴水：反思、潜在线索、情绪和暗流。
- 阳火：主动、表达、创造、快速点燃。
- 阴火：灵感、温度、信任、微光维持。
- 阳土：稳定、承载、组织、长期工程。
- 阴土：收纳、恢复、风险容器、边界保护。

## 资质等级

| 资质 | 判据 |
| --- | --- |
| 下灵根 | 需要大量重复反馈，同类错误常复发，迁移弱。 |
| 中灵根 | 能在同一场景内学习，换场景后需要明显提示。 |
| 上灵根 | 能跨相近场景迁移，能炼成 skill/method。 |
| 地灵根 | 能主动从日志和 replay 中修正，失败后恢复快。 |
| 天灵根 | 少量高质量反馈就能形成广泛、稳定、可追溯升级，同时不丢价值和边界。 |

## 运行规则

评估 agent 时，不只看回答聪不聪明，还要看：

1. 肉身是否承载得住当前修为。
2. 法器是否足以穿过当前苦海。
3. 灵根偏向是否匹配当前任务。
4. 资质是否支持自动修正和迁移。
5. 如果修炼失败，是资质问题、肉身问题、法器问题，还是反馈数据问题。
