# 媒体工具

## 一句话版本
集成 GIF 搜索、YouTube 转录、音乐生成、音频可视化等媒体处理能力。

## 触发条件
- ✅ **触发**：GIF 搜索/发送、YouTube 视频转录/摘要、音乐生成/推荐、音频可视化
- ❌ **不触发**：ASCII 艺术、图片编辑/压缩、视频剪辑、纯文本处理

## 核心能力

### 1. GIF 搜索
- 通过 Giphy/Tenor API 搜索 GIF
- 支持关键词/标签搜索
- 返回 GIF URL 或嵌入代码

```bash
# 搜索 GIF
giphy search --query "happy" --limit 5 --rating g
```

### 2. YouTube 转录
- 提取 YouTube 视频字幕/音频转录文本
- 支持多语言字幕提取
- 可生成视频摘要

```bash
# 获取转录
youtube-transcript --video-id "xxx" --language zh
```

### 3. 音乐生成
- 基于提示词生成音乐片段
- 支持不同风格/情绪/节奏
- 输出音频文件（MP3/WAV）

### 4. 音频可视化
- 将音频数据转换为可视化波形/频谱图
- 支持实时可视化
- 输出图片或视频格式

## 工作流
1. **识别媒体类型**：确认用户需求（GIF/YouTube/音乐/可视化）
2. **选择对应工具**：调用匹配的子模块
3. **处理参数**：处理关键词、URL、风格等参数
4. **执行操作**：调用 API 或本地工具
5. **返回结果**：返回 URL/文件/文本

## 异常处理

### API 调用失败
- **症状**：Giphy/Tenor 返回错误、超时
- **排查**：检查 API Key 是否有效、网络连接、配额是否用尽
- **恢复**：切换备用 API（Giphy ↔ Tenor）、刷新 API Key

### YouTube 无字幕
- **症状**：视频没有内置字幕、转录失败
- **排查**：视频是否提供字幕、语言是否支持
- **恢复**：使用音频识别备选方案、提示用户"该视频暂无字幕"

### 音乐生成超时
- **症状**：生成时间过长、任务超时
- **排查**：服务器负载、音频长度设置
- **恢复**：缩短生成时长、排队等待、提示用户"生成中，请稍候"

### 文件格式不支持
- **症状**：音频格式无法处理、输出格式不兼容
- **排查**：输入格式是否在支持列表内
- **恢复**：转换为支持的格式（如 WAV → MP3）

### 内容安全限制
- **症状**：GIF 搜索返回受限内容、API 拒绝请求
- **排查**：rating 参数设置、内容安全策略
- **恢复**：调整 rating 参数（g/pg/pg-13/r）、过滤敏感内容

## 常见坑点
- ⚠️ GIF API 有每日调用限额，大量搜索需控制频率
- ⚠️ YouTube 转录依赖视频是否有字幕，不是所有视频都支持
- ⚠️ 音乐生成耗时较长，需设置合理的超时和进度提示
- ⚠️ 音频可视化需要足够的计算资源，大批量处理建议离线
