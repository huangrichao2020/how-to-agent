# 供需体感训练法 (Supply-Demand Trading Framework)

## 核心来源
抖音 @踏浪前行「给正在读书学生的建议」(2026-05-09)

## 核心逻辑：供需四阶段循环

```
紧缺 → 预期炒作 → 业绩兑现 → 过剩 → 出清 → 新一轮紧缺
  ↑                                              ↓
  └────────────── 周期循环 ←─────────────────────┘
```

### 四阶段详解

| 阶段 | 供需状态 | 股价表现 | 交易动作 | 时间窗口 |
|------|----------|----------|----------|----------|
| **1. 紧缺** | 产能缺口客观存在，业绩还没出来 | 股价未动或微涨 | 建仓（买因果） | 缺口拉大 + 新产能 3-9 个月后投产 |
| **2. 预期炒作** | 活还没干，业绩没出 | 资金先涨 | 持有/加仓（跟住相） | 从拉升节奏判断"什么缺了" |
| **3. 业绩兑现** | 产能陆续投产，缺口收窄 | 股价反而跌 | 减仓（住相破裂） | 预期已 price in |
| **4. 过剩** | 产能过剩，消化低效产能 | 持续跌几年 | 空仓等待 | 产能出清后进入新一轮紧缺 |

## 关键洞察

### 1. 感知连续曲线
> "信息对错不重要，重要的是信息流形成的感知连续曲线、标准质变特征和异常突变。"

- **单个信息**：不重要（今天扩产还是减产）
- **信息流**：连续 3 个月看到扩产 → 形成曲线方向
- **标准质变**：扩产速度突然加快 = 供需即将反转
- **异常突变**：某环节突然停产 = 新的缺口出现

### 2. 老油条体感
> "老油条的反映是反过来的，拉什么的时候，就知道什么缺了，再拉什么是到最后了。"

- 拉 CPO → 光模块紧缺
- 拉 HBM → 存储紧缺
- 拉液冷 → 散热紧缺
- **最后拉什么** → 行情快结束了

### 3. 可复制的体感训练
1. **建库**：用 AI 追踪半导体/光通信产业链，从上游到下游建立产能产量数据库
2. **找矛盾**：在供需流转过程中找缺口 → 对应拉升的核心个股 → 理解供不应求
3. **看时间差**：供需缺口拉大时，对应环节产能还有 3 个月/9 个月/半年才投产
4. **看过剩**：观察产能从紧缺到过剩，股票怎么跌下来

## 与现有方法论融合

| 现有方法 | 供需体感补充 |
|----------|-------------|
| 执念六阶段 | 增加了"供需驱动执念形成"的因果链 |
| 五步分析法 | 盘中增加"产能时间线"维度 |
| 因果性检验 | 区分"供需因果"和"概念相关性" |
| 时间门纪律 | 增加了"3-9 个月投产窗口"的长周期视角 |

## 在 AHOT Generator 中的应用

在 `pre_market.py`, `post_market.py`, `personalized.py` 的系统 prompt 中注入：

1. **供需阶段判断**：对每个板块/持仓股，判断处于哪个阶段
2. **信息流方向**：分析近期新闻/公告形成的曲线方向
3. **老油条信号**：识别"最后拉什么"的尾声信号
4. **因果性检验**：区分真供需驱动 vs 纯概念炒作

## 使用示例

当用户询问某只股票（如中际旭创 CPO）时：
1. 查当前产能状态（紧缺/过剩？）
2. 查新产能投产时间表（3-9 个月后？）
3. 查股价是否已提前反应（预期炒作阶段？）
4. 给出操作建议：建仓/持有/减仓/空仓
