# Source Map: AI Training Methodology

External source:
[hmy1990116/ai-training-methodology](https://github.com/hmy1990116/ai-training-methodology/tree/main)

This source is useful because it connects three things that are often split:

1. enterprise AI adoption diagnosis;
2. agent skill design;
3. sales, delivery, renewal, and referral loops.

## Mapped Concepts

| Source idea | Use inside how-to-agent |
| --- | --- |
| Two-layer decomposition | Diagnose enterprise workflows before writing agent skills |
| Four-quadrant pain assessment | Pick high-repeat, high-time, low-value, rule-heavy scenes first |
| Six-dimension skill evaluation | Decide automation level and human-review boundary |
| A/B/C skill types | Package full automation, AI-led workflow, and AI-assisted decision separately |
| CEO course structure | Use training as cognition shift plus artifact production |
| Business playbook | Build acquisition, conversion, delivery, and renewal hooks |
| Social ecommerce case | Show how one industry becomes a skill portfolio and rollout plan |
