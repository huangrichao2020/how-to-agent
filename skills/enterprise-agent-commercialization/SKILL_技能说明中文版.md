# 企业级 Agent 商业化

把企业级 agent 工作变成可售卖、可交付、可复购的业务变化方案。

## 核心立场

不要先卖"一个 AI agent"。先卖对客户自身业务流程的清晰诊断，再把诊断变成可见 artifact 和下一步付费路径。

```text
业务痛点 -> 流程地图 -> 优先场景 -> skill specs
  -> 工作坊证明 -> quick win -> 落地节奏 -> 复购
```

## 什么时候用

用户要求以下内容时使用：

- 企业级 agent 产品设计；
- AI 内训或 CEO 工作坊设计；
- agent 咨询、诊断、落地服务；
- 销售转化、跟进、复购、续费；
- 把业务场景变成可收费 skill 包。

## 输出标准

好的输出必须给商业 artifact，而不是泛泛建议：

- 买方画像和触发事件；
- 流程痛点地图；
- Top 3-5 agent 场景；
- A/B/C skill 类型组合；
- 工作坊或诊断产品；
- 转化钩子；
- 30/60/90 天落地计划；
- 复购或顾问服务；
- 风险和人审边界。

## 工作流

1. **确认买方和触发点。**
   谁付钱、什么事件让问题变急、客户关心哪个业务指标。

2. **画管理层视角。**
   列出核心流程和支撑流程，用重复频率、耗时、战略价值、规则清晰度评分，选出 Top 3-5 个 AI 改造场景。

3. **拆执行层视角。**
   把优先场景拆成原子动作，标明输入、输出、数据形态、错误风险和人审需求。

4. **归类 skill 类型。**
   使用：
   - A：规则清晰、低风险任务，全自动；
   - B：AI 主导流程，人类确认关键节点；
   - C：AI 辅助决策，人类保留所有权。

5. **设计付费入口产品。**
   优先做诊断工作坊，产出成熟度地图、流程地图、场景优先级矩阵、第一个 skill spec 和落地提案。

6. **设计转化路径。**
   为引流、咨询、交付、复购分别设计钩子。每个钩子都要制造下一次对话的理由，不靠假稀缺。

7. **包装落地节奏。**
   写 30/60/90 天计划：
   - 0-30 天：quick win 和 A 类任务；
   - 30-60 天：AI 主导流程和团队采用；
   - 60-90 天：决策辅助、看板和治理机制。

8. **让证明可见。**
   设计 before/after 复盘、人效指标、质量变化、授权案例片段，用于复购和转介绍。

## 转化钩子

| 阶段 | 钩子 |
| --- | --- |
| 引流 | 行业内反直觉痛点或标杆对比 |
| 咨询 | 客户自己答不清的诊断问题 |
| 交付 | 基于客户自身流程产出的具体 artifact |
| 复购 | before/after 证明 + 下一步杠杆 |

## 反模式

- 从模型、厂商或 prompt 技巧开始。
- 付费诊断前就卖定制开发。
- 给管理层讲工具操作，而不是业务杠杆。
- 第一次咨询把方案全讲完。
- 用假稀缺或打折替代机会成本。
- 高风险决策没有人审边界。
- 把通用培训课件包装成企业级 agent 战略。
